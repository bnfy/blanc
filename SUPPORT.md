# Blanc support

Blanc supports its newest public stable release from publication until the next
stable release is published. That next release ends support for every earlier
version; Blanc does not maintain parallel or long-term-support branches. The
current version is listed on the
[downloads page](https://blancbrowser.com/download/) and in
[GitHub Releases](https://github.com/bnfy/blanc/releases/latest).

Support covers installation, updates, documented Blanc features, and
Blanc-operated website and sync services on the operating systems named by the
current release. It does not cover modified builds, obsolete versions,
third-party websites or services, or operating systems outside the current
release's published requirements. General support is best effort through
`support@blancbrowser.com`; bug reports and feature requests may use
[GitHub Issues](https://github.com/bnfy/blanc/issues).

Security updates are provided only for the supported current release. Report a
suspected vulnerability privately and follow the response and remediation
timelines in [SECURITY.md](SECURITY.md).
