Privacy & Security

Blocking

Blocking provider Changes take effect after restarting Blanc. uBlock Origin protects regular tabs. Blanc’s browser engine can load uBO only in saved sessions, so private sessions stay in memory and use Blanc Blocker. Each provider keeps separate site settings.

Filter lists update automatically. Executable resources update with Blanc releases; custom resource URLs and cloud storage are unavailable. Turning blocking off removes cosmetic CSS; reload a page to undo changes already made by scriptlets.

Block ads & trackers Stops ads and the hidden trackers that follow you from site to site. On by default.

Sites listed here load with ad-blocking turned off, e.g. for sites that break under it.

Calls and connections

IP address in video calls Standard limits calls to your default network route. If a call stutters or won't connect, try Compatibility; it can reveal local network addresses to the site. Strict is for application-proxy users.
Call audio Automatic keeps conversation delay as low as possible. Stable targets about 400 ms of receive buffering. Resilient targets about 1 second for severe crackling or chopped speech, making back-and-forth conversation slower. Start a new call after changing it.
Encrypted DNS Encrypts the behind-the-scenes lookups that turn a web address into a connection, so someone sniffing those lookups can't read the names. It does not hide the sites you visit from your network, and it makes the DNS provider someone you trust. Automatic uses encryption when it can and may fall back to ordinary DNS — safe to leave on. If a Wi-Fi login page won't load, switch to Automatic or Off temporarily.
Custom provider address The secure DNS address your provider gave you (an https:// link), e.g. https://dns.nextdns.io/<profile>. That address isn't valid — the previous provider is still in use.

Architecture

Blanc uses Chromium through Electron to render websites. Updates to Electron and Chromium arrive with new Blanc releases and replace the whole app. Applying an update requires restarting Blanc.

How Blanc works ↗ Source code ↗ Privacy policy ↗ Release notes ↗

Extensions and password managers

You can browse Chrome Web Store pages, but Blanc cannot install Chrome extensions.

On macOS, Windows and Linux, Blanc offers explicit login fill from the installed 1Password app. This integration does not save passwords or fill automatically.

Connections Blanc can make

Blanc connects to websites you open and GitHub for app updates. Searches and enabled suggestions go to your selected search provider; DNS lookups use your system or selected DNS provider. Selecting Google sends searches and eligible suggestion prefixes to Google.

Enabled usage measurement goes to a Blanc-owned Cloudflare collector and, when configured, its Google Analytics mirror. Sync, Patron, 1Password and tab handoff make separate connections when configured or requested. This describes behavior; it is not a live network monitor.
