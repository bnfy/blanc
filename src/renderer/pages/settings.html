Profiles

Named profiles keep separate cookies, site data, Favorites, history, downloads, and remembered permissions. Device settings and Patron status stay shared; Profile Sync belongs to Personal only.

Privacy & Security

Block ads & trackers Stops ads and the hidden trackers that follow you from site to site. On by default.
IP address in video calls Standard limits calls to your default network route. If a call stutters or won't connect, try Compatibility; it can reveal local network addresses to the site. Strict is for application-proxy users.
Call audio Automatic keeps conversation delay as low as possible. Stable targets about 400 ms of receive buffering. Resilient targets about 1 second for severe crackling or chopped speech, making back-and-forth conversation slower. Start a new call after changing it.
Encrypted DNS Encrypts the behind-the-scenes lookups that turn a web address into a connection, so someone sniffing those lookups can't read the names. It does not hide the sites you visit from your network, and it makes the DNS provider someone you trust. Automatic uses encryption when it can and may fall back to ordinary DNS — safe to leave on. If a Wi-Fi login page won't load, switch to Automatic or Off temporarily.
Custom provider address The secure DNS address your provider gave you (an https:// link), e.g. https://dns.nextdns.io/<profile>. That address isn't valid — the previous provider is still in use.

1Password

Fill a matching Login item from your installed 1Password app when you ask. While this is on, Blanc checks pages for a login form so the island can offer Fill — it never reads what you type and never contacts 1Password until you ask.

1Password app
Fill logins from 1Password In 1Password, open Settings → Developer and turn on Integrate with 1Password SDKs
1Password account The email address you sign in to 1Password with. An account ID also works. Stored only on this device.

Use View → Fill Login from 1Password or /1password. On Mac: ⌥⌘P.

Help improve Blanc Counts active users and which start-page layouts and local features get used. Sends a random install and session id, app version, platform, architecture, coarse OS major, and fixed feature names; never URLs, searches, page content, or private-tab activity. The install id is stored on our side only as a one-way hash. Turn this off to stop sending it.

Clear browsing data

Removes cookies, cache, and site data for every site. You'll be logged out of everything.

Sync

Sync your favorites and settings across devices — and, if you turn it on below, this device’s open tabs. Blanc encrypts everything on this device with your passphrase and stores only unreadable data — we can’t read it, and can’t recover it if you forget your passphrase.

Diagnostics

Blanc keeps a local, 50-event crash ledger with timestamps, process type, and failure reason. It never includes URLs, page titles, history, profile names, account data, identifiers, quiet-tab state, or closed-tab state, and nothing is sent automatically.

Blanc Patron

Blanc Patron unlocks Named Workspaces on every platform, and on macOS three extra Dock colorways — ember, plum, and gold. A one-time founding license activates once, with no further contact. A monthly or annual subscription checks in with Polar about once a day — your license key and activation id only, never browsing data — to confirm it’s still active. On a lapse, existing workspaces stay available while creating new ones pauses; on macOS, colorways quietly revert to Paper.

Help

Something broken, or working in a way it shouldn’t? Reports go to Blanc’s public issue tracker on GitHub. Saying which version you’re on, which operating system, and what page you were looking at makes a report much faster to act on.
