# Split View divider and pane menus

Pinned Electron reference: merged PR #993, 98ea48fc01d79759cfef40009b18cf69715eaed8. The persistent two-pane header divider supports pointer drag, Arrow Left/Right (2 percent, Shift 5 percent), Home/End (20/80 percent), Enter/Space and double-click reset. Its accessible separator exposes current/min/max values and left-pane percentage. Native resize validates the ordered, visible persistent tab pair and range before updating Chromium's actual split ratio. The handle persists across snapshot paints so pointer capture and keyboard focus survive width updates.

Pane headers add Reload and an Actions menu: Reload, Mute/Unmute tab, Pin tab, Remove from Split View and Close tab. Actions use the original pane ID and recheck visible pair membership. Escape returns focus to the pane menu trigger; outside clicks dismiss. Pin/remove/close use existing native ownership handling. Closing a pane is not a whole-split Recently Closed entry.
