Diagnostic evidence, not completion of the speculation acceptance row. Two isolated
regular/private schedules used the existing native binary and authenticated Blanc
Blocker assets against a disposable loopback HTTPS server with exact fixture SPKI
trust. No feature enable/disable override was supplied by this harness. This does
not inventory all browser defaults, Playwright launch defaults or variations.

Both schedules generated two real speculation-rules prefetch requests. Server
headers contain `sec-purpose: prefetch`; CDP records Ready /
PrefetchSuccessfulButNotUsed; native logs contain explicit allow decisions before
navigation for all four URLs, classified mainFrame. The candidate tracker host
000491b06a.com was allowed too. Its historical WebTransport refusal does not prove
a mainFrame refusal, so the fixture's `-blocked` URL suffix is an intended probe
label, **not an observed blocking result**. No bypass is inferred from an explicit
engine allow. A valid refusal control is still required.

cache reuse. The later cross-origin navigation produced a fresh request. Dedicated
consumption attribution remains open; recorded histograms are raw data, not decoded
success assertions. The validator checks these observations without converting
