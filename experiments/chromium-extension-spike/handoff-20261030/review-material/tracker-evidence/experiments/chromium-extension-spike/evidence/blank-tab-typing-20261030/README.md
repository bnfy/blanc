On the before-fix isolated regular fixture, native `⌘A` produced a trusted modified key and left the Island closed; computed style showed the Commands button had `display:none` and zero size and the accessibility tree omitted it. The recorded failed test's message says the native button failed to open; no button click was possible because it was hidden. `Chromium Preview/evidence/blank-native-shortcuts-20261030/result.json` and `chip-geometry.json` retain that result.
