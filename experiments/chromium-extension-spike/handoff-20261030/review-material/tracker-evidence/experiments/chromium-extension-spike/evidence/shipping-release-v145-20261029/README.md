# Shipping Blanc v1.45.0 reference

On October 29, GitHub's published latest release API reported v1.45.0, `target_commitish` 6f1bc523d2f0d432d5c4119b9f7ec22a324dbd2d. `git ls-remote` independently resolved `refs/tags/v1.45.0` to the same commit; the commit was fetched without changing the worktree. `release-notes.md` is extracted from that commit; `desktop-changed-files.txt` inventories desktop implementation and schema/copy changes from the prior v1.44.1 source 3b0c000b569ee33a1548dd1b9a60817fae9288a6.

The release adds opt-in encrypted Shared Spaces and cross-device Recently Closed, passphrase-free Sync with device pairing and recovery, optional launch Sunrise (off by default and local to each device), opt-in routing of user-opened new-tab links, and iPhone pairing. It updates the vertical-tabs Space/group controls and fixes background-tab Space switching and non-square favicon rendering. These are current product requirements; presence in this list is not a claim that Chromium implements them. Private/internal/local data exclusions and the precise shipping consent, encryption and persistence semantics remain part of the contract. The existing development Start Page derives from v1.44.1, so it does not yet contain the new launch Sunrise or iPhone-pairing entry. Sync and Spaces were already incomplete and must now target the v1.45.0 behavior. Other desktop changes need file-level review before asserting parity.
