# Island interface language candidate

Reference: latest published Blanc v1.45.1, source `85883b1afa11375e1300130914d6f40c5388af21`, rechecked 2026-10-30. Shipping resolves explicit selection or preferred system languages into six selectable catalogs, retaining the system region for formatting. Chromium's reviewed Island baseline had only English. Rather than rebuilding Island text, `interface-locales.mjs` validates and bundles exact published en, de, es, fr, it and pt-BR catalogs for the existing shipping-derived Island and overlay renderer. It uses browser preferred languages and navigator region as an interim approximation; this is not the shipping explicit setting or OS-region API. Nine keys used by the older prototype that are absent from current shipping catalogs fall back to the older English text. The normal 158 assets-only preparer now builds the bundle after the guarded copy-command messages.

Fourteen focused cases compare selection, formatting and each complete catalog with the published source, including French Canada, Portuguese Portugal, regional variants, unsupported language and old-key fallback. In isolated browser fixtures with script-injected navigator preferences, regular fr-CA produced French Island and overlay labels and fr-CA formatting, and verified-private pt-PT produced Brazilian Portuguese labels and pt-PT formatting. Both owned browsers exited zero and passed profiles were removed. Framework `49b25ce10ef94d20f2dee38594bd7568a00fd67000647f655214def66e40f35b`, 78-file manifest `c8a21c3766296713ced67b118aead8610cfb842c3e6bb1fbd3020e60d5f9e52a`; raw browser results and isolated full asset preparation are under `Chromium Preview/evidence/interface-locales-v2-20261030`. Preparation produced 78 changed assets requiring qualification; it did not touch the real generated output. Source and receipt hashes are in `result.json`.

This is not full interface localization: the language chooser, persistent explicit preference, restart semantics, actual OS region, every dynamic key, human review, screen-reader/visual behavior and Windows/Linux remain open. Browser checks deliberately override navigator in fixture documents, not the OS. Start Page, native dialogs and other surfaces have separate implementations and evidence. The approximately 1.05 MB bundle has not been measured for latency. v37 contains unqualified changes and selected-search isolation remains open; the candidate has not been promoted. No native build, signed artifact or user profile was changed.
