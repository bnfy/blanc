# Settings hub routing — source draft, 2026-10-30

Shipping reference verified: Blanc v1.45.1, source `85883b1afa11375e1300130914d6f40c5388af21`. The source draft adds a capability-gated route from ordinary Settings to the existing Blanc blocking/language settings page, with an explicit link to Chromium Settings. Older builds retain native Chromium Settings in regular windows; in private windows the route uses the existing supported Blanc page, preserving the private context and making Chromium Settings accessible via the explicit link. Concurrent general and Blocking requests are serialized rather than dropping one.
