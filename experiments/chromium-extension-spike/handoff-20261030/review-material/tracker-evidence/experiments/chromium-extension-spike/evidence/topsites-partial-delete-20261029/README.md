## Executed v7 candidate checks and preserved Store interception crash

`v7case1.json` retained the failed full fixture on framework `d8ac07d95573e10607bacddcba6d67c8b87ca64753247e2364e30c62eb169df8`. Before failure, fresh-profile, partial-delete, eight recorded in-flight responses after deletion acknowledgment, immediate/new-handler absence, and inactive-Billboard pin/icon invalidation checks passed. While the test synthesized a Store HTTP response via CDP `Fetch.fulfillRequest`, the isolated browser crashed at `chrome/common/google_url_loader_throttle.cc:336` because `response_head->parsed_headers` was null; its Page.navigate and Browser.close timed out after the crash. Source analysis shows `InterceptionJob::ProcessResponseOverride` constructs the synthetic response head without assigning `parsed_headers`, whereas the Store throttle checks that member. This is evidence of an actual crash on the synthetic interception path; normal Store network behavior has not been established from it. The failed browser process exited and its CDP port closed; no forced kill. Independent Store-crash investigation is separate.

`storeseed1.json` passed using a fresh disposable profile and a local test-only extension with `history` permission. `chrome.history.addUrl` seeded the built-in Store URL without requesting a Store navigation; native History Mojo confirmed one visit, and the built-in URL became eligible after an unrelated local-history deletion triggered the TopSites refresh. The emitted receipt phrase “no Store network attempted” is stronger than the evidence: the fixture records its own server and uses a closed proxy/resolver, but did not instrument every host-level connection. Its browser exited normally; no extension was installed into the development or permanent profile.

`v7remaining1.json` passed in another disposable profile. It reconstructed prerequisite history/pin state, then checked assisted revisit after a real native requery, complete history clear, ranking and pin unavailable/retry controls visible and programmatically focusable/clickable in all four layouts using synthetic one-shot WebUI reply failures, and private native TopSites/pin responses. Both fixture browser phases exited normally. This does not induce actual history database failure, test physical keyboard/VoiceOver, prove all layouts' pixel fidelity, or resolve the Store interception crash. OnURLsModified title refresh and Chromium's delayed natural re-ranking after a visit remain open.
