The canonical native source now drafts `CommittedSecurityWarning`: it requires a live, non-crashed primary frame, a noninitial committed entry, no pending entry, and the same visible and committed entry and URL before asking Chromium's `chrome_security_state::GetVisibleSecurityState` and `security_state::GetSecurityLevel`. It emits only `warning` or `dangerous`, otherwise null; it does not infer or emit a secure classification from a URL. Chromium's native interstitials are not overridden. `prototype/host.js` projects only those two explicit values to a generic localized “Not secure” badge and site-information summary. Its origin omits userinfo, path, query and fragment; no certificate record, exception approval, exception-removal action, or fabricated permissions are supplied. This is an intentionally incomplete site-info implementation, not full shipping certificate/permission parity.

## Document-lifetime revalidation

The initial source retained a navigation-entry pointer across Chromium's security-state read. The revised source captures the entry ID and URL, a weak WebContents reference and a weak **document** reference before the read; afterward it rechecks that the contents and document still exist, the same committed entry remains visible with no pending navigation, and the frame and URLs still agree. A weak document reference is used because a RenderFrameHost can host another document without changing its host identity. Changed, destroyed or ambiguous state yields null, not a secure classification. The previous native source is preserved as `native-warning-v1.cc`.

`source-lifetime-check.json` records source-order and identity assertions, with current native source SHA-256 `f314fd8c484aab7331b2ac4f2be091aa988333118afc2c1a6ce50d9d0df9cf6e`. This is a structural check, not proof that real Chromium callbacks reenter or that all navigation races are covered. The native code remains unbuilt; real held-navigation, same-URL replacement, crash/destruction, interstitial and certificate tests remain required after the separately authorized environment and build steps.
