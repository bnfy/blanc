# Owned singleton-window corroboration draft

This isolated, unrun diagnostic retains AXG1 and the strict AX geometry match unchanged. AXG1 reported one AX window, unsupported AX position/size, and an available focused-window value, but exited before comparing them or reading that window's other attributes. This variant records only fixed status/boolean results for the singleton AX element's `AXRole == AXWindow`, equality with `AXFocusedWindow`, `AXFocused` and `AXMinimized`, even when geometry is unavailable. AX errors, unsupported values and absent focused windows remain unknown.

Additional corroboration records the count of distinct CDP window IDs for the three explicitly owned fixture tabs; a read-only NSWorkspace frontmost-PID equality boolean; and counts from on-screen CG windows whose owner PID equals the direct child browser PID. The system-wide CG list exists transiently in process memory. The code reads only owner PID for non-owned entries and does not save window IDs, PIDs, titles, URLs, names or arbitrary error text. For owned entries it reads layer and bounds; it records count of owned, eligible layer-0, unreadable and matching entries, plus truncation. Zero CG matches is not proof of no browser window, since on-screen filtering, inaccessible metadata and truncation matter.

A singleton AX window and matching CG/CDP counts do not establish cross-API identity or native `Widget::IsActive`; frontmost and AX samples are asynchronous indicators. This variant makes no heuristic match, still fails before the click when AX geometry cannot be uniquely matched, and does not affect product activation. It will not modify or activate user windows directly; the inherited test brings its own fixture window forward and can change system foreground. The fresh test profile contains synthetic localhost pages. Review and coordinate that effect before any run.

Synthetic tests: `python3 observer.test.py`, `python3 corroboration.test.py`, `node --test bridge.test.mjs` (7 Python and 15 Node cases). Native AppKit, CG, AX and real browser behavior are untested. No credential, user profile, build output or earlier evidence is changed.
