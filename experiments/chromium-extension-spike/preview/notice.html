Current status, updates & withdrawal notice ↗

Update safely

Quit the preview and save a closed backup of its preview profile. Verify the replacement’s published checksum and Developer ID, then replace only Blanc Chromium Preview.app. Shipping Blanc is separate.

If this preview is withdrawn

Quit it and use shipping Blanc. Remove only the preview app; keep its profile for recovery. This preview cannot be remotely disabled.

Roll back without risking saved tabs

Keep the newer profile separately. Use the older signed app with its matching closed profile backup, or start with a fresh preview profile. Never open an upgraded profile with an older app.
