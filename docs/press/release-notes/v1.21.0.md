# Blanc 1.21.0

## Improved

- **Blanc now remembers each window's size, position, and display mode.** Quit and reopen Blanc to restore normal, maximized, or fullscreen windows where you left them on macOS, Windows, and Linux. Windows you explicitly close are forgotten instead of returning later.
- Start pages now use the Sunrise visual system across Ledger, Billboard, Shelf, and Tally, with warmer artwork, more consistent controls, and clearer layout-specific character.
- Newsreader typography gives start-page invitations and editorial moments a more expressive voice while the rest of Blanc retains its familiar interface type.

## Fixed

- Websites can no longer set or clear Blanc's operating-system app badge through the Badging API.
