# Blanc 1.42.0

## Added

- **Search priority results.** A new setting in Settings → General, under
  Island, puts search suggestions first as you type: the search for what you
  typed and your search engine's suggestions come before your tabs, groups,
  Spaces, Favorites and history, and Enter searches. It is off by default, so
  the order you know stays the same until you turn it on.

## Fixed

- On Windows and Linux, the first permission prompt in a window no longer
  keeps the keyboard, so what you type next goes to the page instead of being
  lost.
- With Auto-hide set to Float, the floating Island casts one shadow again,
  without a second outline along its bottom edge.
