# Blanc 1.48.0

## Added

- **Glance over a split.** With Split View showing, Glance now opens as a
  floating card over both panes, from a tab's Glance button in the ⌘L panel,
  a tab's menu, the View menu (⌘⇧G on a Mac, Ctrl+Shift+G on Windows and
  Linux) or `/glance`. Clicking between the two panes keeps the Glance open,
  and if you close one pane, the other fills the window with the Glance still
  over it. Before, the Glance button looked available over a split but did
  nothing. Choosing Glance for one of the split's own two tabs still takes
  that tab out of the split and floats it over the other, and the card's
  **Keep as split** is hidden while a split is showing.

## Fixed

- After choosing **Continue** past a certificate warning on a local or
  private-network address, the page couldn't open live connections
  (WebSockets) back to the same address, so consoles and live views such as
  Proxmox's couldn't connect. They now use the same choice, for that same
  address and certificate only.
