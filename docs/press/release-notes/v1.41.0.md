# Blanc 1.41.0

## Added

- **Clock Font & color.** Choose how the Billboard Start Page's clock looks,
  like the iOS Lock Screen: open **Customize** and pick **Clock**, or
  right-click the clock. Pick a font (Instrument Sans, Instrument Sans
  Condensed, Inter or Roboto Flex), its weight and its height, then a color:
  **Automatic** or one of eight colors with a tone. **Glass** bends the
  page behind the numerals like glass; **Solid** draws them flat. Every
  clock now has a soft shadow so it stays readable on any background.
- **Start Page pins.** Pin up to eight pages to the Start Page, and they come
  first on every layout, newest first. Pin a Billboard tile, a favorite on
  Ledger, Shelf or Tally, a favorite on the Favorites page, or the current
  page from a tab's right-click menu with **Pin to Start Page**. Pins sync
  with Profile Sync.

## Fixed

- After a site asks for a permission, the keyboard goes back to that page
  instead of to a tab you can't see.
- On the Billboard Start Page in dark mode, a tile's × is visible again.
