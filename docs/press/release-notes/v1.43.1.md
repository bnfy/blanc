# Blanc 1.43.1

## Fixed

- Blanc 1.43.0 didn't start on Linux distributions whose C library (glibc) is
  older than 2.38, such as Ubuntu 22.04 LTS and Debian 12, so Linux updates
  were held at 1.42.1. Blanc 1.43.1 needs only glibc 2.28 and starts on
  Ubuntu 22.04 LTS, and Linux updates resume with it. If you downloaded the
  1.43.0 AppImage, download 1.43.1 again; 1.43.0 can't start to update itself.
