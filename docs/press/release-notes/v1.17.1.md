# Blanc 1.17.1

## Fixed

- Blanc no longer shows its own username and password dialog for HTTP authentication challenges, including HTTP Basic, Digest, and proxy prompts. A website's own sign-in page and forms are unchanged.

## Security

- Bookmark and browser-profile imports now read each file through a single handle, so a file changed or replaced while it is being read cannot bypass Blanc's size and type limits.

## Known limitation

- A site that relies on the browser's built-in HTTP authentication prompt, rather than its own sign-in page, can no longer be signed into in Blanc.
