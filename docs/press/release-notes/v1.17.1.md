# Blanc 1.17.1

## Fixed

- Blanc no longer shows its own username and password dialog for HTTP authentication challenges, including HTTP Basic, Digest, and proxy prompts. A website's own sign-in page and forms are unchanged.

## Known limitation

- Sites and proxies that rely on a browser-managed HTTP authentication prompt no longer get one in Blanc; without a site-provided sign-in flow, access may fail with a 401 or 407 response.
