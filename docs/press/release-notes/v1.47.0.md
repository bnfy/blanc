# Blanc 1.47.0

## Added

- **Default page zoom.** Settings → General → **Default page zoom** sets the
  size web pages open at, from 50% to 200%, and open tabs change at once.
  Zooming in or out on a site (⌘+ and ⌘− on a Mac, Ctrl++ and Ctrl+− on
  Windows and Linux) saves a size just for that site in the current profile,
  and every tab on that site follows; ⌘0 or Ctrl+0 forgets it and returns to
  the default. Settings lists the sites with their own zoom, each with
  **Remove**, plus **Clear all**. Private tabs save nothing, and zoom you set
  in earlier versions carries over. Sign-in popup windows aren't covered yet:
  they stay at 100%.

## Changed

- Zooming in and out now steps through the same sizes as Chrome (… 75%, 80%,
  90%, 100%, 110%, 125% …), so zooming back always lands on 100%.
- On Windows, with Island auto-hide on, the band along the top of the page
  that drags the window is 10 pixels tall instead of 6, so it's easier to
  grab. The top few rows of the page under it no longer take clicks while the
  Island is tucked away. macOS and Linux keep 6 pixels.
- Blanc now runs on castLabs' Electron for Content Security 45.2.1, with
  Chromium 156.0.8078.75, instead of 44.9.3 with Chromium 152. The optional
  uBlock Origin blocker remains available on this version.

## Fixed

- With sync on and a shared Space open or set aside, quitting Blanc while a
  shared Space was arriving from another device could overwrite the saved
  windows file with an empty one. Quitting now keeps it.
