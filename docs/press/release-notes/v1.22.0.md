# Blanc 1.22.0

## New

- **Navigate Blanc with customizable mouse gestures.** Enable Mouse gestures in Settings → General, then hold the right mouse button and draw before releasing. On a Mac trackpad, hold Option while clicking and dragging with one finger. Blanc includes gestures for Back, Forward, New tab, and Close tab, and lets you draw or reassign gestures for navigation, tabs, Reload, and the Island.

## Improved

- The onboarding dialog now fully covers the start page, uses rounder geometry, and shows a current miniature of the Island.
- Billboard clocks use more natural digit spacing, keep the meridiem close to the time, and remain centered in 24-hour locales.

## Fixed

- Mahjong now keeps hints, Undo, and Rescue aligned with the current board while preserving its standalone-tab behavior and game documentation.
