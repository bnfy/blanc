# Blanc 1.26.0

## Added

- Settings → Help now shows the running Blanc, Electron and Chromium versions, platform and architecture. Links explain how Blanc works, privacy choices, source code and release notes. Check for updates uses the existing update flow; applying an update still requires restarting.

## Refined

- The background behind the Island follows wallpaper fades and page color changes after loading. Sampling stays on the device; private tabs retain their theme background.
- Setup and privacy settings explain search suggestions and pseudonymous usage measurement, their recipients, and when sending starts. Fresh defaults and saved choices are retained. Opening the privacy explanation preserves unsaved setup choices.

## Fixed

- Ctrl/Cmd-click and middle-click open eligible website links in new tabs while preserving their navigation and sandbox restrictions.
- A rejected Windows update can be retried through Check for Updates without leaving the restart action stuck.

## Security

- Windows requires a completed publisher check and matching verified installer bytes before installation. If verification cannot complete, installation is deferred for a later retry.
- Linux refuses launches that disable Chromium's sandbox, including an AppImage launcher's automatic fallback. On systems that cannot provide the required sandbox, Blanc shows guidance instead of opening browsing windows. This does not change the system's user-namespace or AppArmor configuration.
