# Blanc 1.24.0

## Added

- A free, optional time-of-day wallpaper for the start page. Sunrise now follows your local clock through dawn, day, dusk, and night, with no location permission or network requests. Enable **dynamic wallpaper** beside the layout picker or **Time-of-day wallpaper** in Settings.
- The wallpaper works in every start-page layout and private tabs. Turning it on or off fades over two seconds; reduced-motion settings switch immediately. If you use Sync, your wallpaper preference follows your devices.

## Fixed

- Linux AppImages no longer require FUSE 2. The packaged desktop shortcut also passes URLs correctly and no longer adds unintended command-line arguments. Existing shortcuts may need to be integrated again to receive that correction.

## Security

- Updated the official Electron runtime to 44.5.1, including upstream security fixes.
- Updated dependency inputs to address brace-expansion advisories and the website's devalue advisories.
