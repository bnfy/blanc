# Blanc 1.10.0

## Added

- On macOS, the optional 1Password integration can now show a small key hint when the active page declares a visible current-password field. The bounded local check reads form structure only, never field values or page text, and does not contact 1Password. Filling still begins only when you explicitly choose the hint, use **View → Fill Login from 1Password**, press **Option-Command-P**, or run `/1password`.
- The 1Password section in Settings now includes **Verify**, which saves the entered sign-in email or account ID and confirms the connection through the installed 1Password app.

## Changed

- 1Password setup decisions, errors, and success feedback now appear in a Blanc-styled in-app capsule instead of stock dialogs. When several Login items match, the native picker opens beside the detected login field.
- 1Password setup copy now leads with the email address used to sign in to 1Password while continuing to accept an account ID.

## Fixed

- 1Password fill attempts now withdraw cleanly when you navigate, switch tabs, open another Blanc surface, or dismiss an authorization prompt, preventing late results from appearing over or filling a page you have left.
- The fill capsule now preserves keyboard cancellation, accessible status announcements, and success-message timing while hovered or focused.
