# Blanc 1.33.0

## Added

- Blanc's interface is available in Italian, machine-translated, alongside
  German, Spanish, French and Portuguese (Brazil). If your system uses
  Italian, Blanc now follows it; choose English or another language any time
  in Settings → General → Language.

## Fixed

- In Spanish, French and Portuguese, the `/theme` hint and its entry in the
  slash command reference showed translated appearance names (for example
  "oscuro" or "sombre"), and typing them after `/theme` did nothing. They now
  show `system`, `light` and `dark`, the words `/theme` accepts in every
  language.
