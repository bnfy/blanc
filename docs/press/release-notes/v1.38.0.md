# Blanc 1.38.0

## Added

- **Your own Start Page image.** Open **Customize** on the Start Page and
  choose **Your image** under Wallpaper to show a JPEG or PNG of your own, up
  to 25 MB. **Wash** (Auto, Light, Dark or Spotlight) and **Fade** keep the
  page readable over it. Blanc keeps a resized copy on this device only, with
  location, camera and time details removed. It isn't synced, and private
  tabs never show it. Settings → General → Start Page image offers the same
  choice.
- **A Start Page color.** Choose **Color** under Wallpaper to paint the Start
  Page in one of the eight colors Spaces use, as a **Soft**, **Solid** or
  **Gradient** fill. Turn on **Match each space's color**, and a window that
  belongs to a space shows that space's color instead. The color settings
  sync with Profile Sync; an image chosen on this device still takes priority
  here. Private tabs never show the color.
