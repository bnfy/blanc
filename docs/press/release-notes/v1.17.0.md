# Blanc 1.17.0

## Fixed

- Named Workspaces preserve live drafts, history, and page state when you switch, with reliable saving, recovery, ordering, and deletion controls.
- Sign-in flows can now return from Blanc to installed desktop applications such as Claude after browser approval completes.
- Blanc's built-in 1Password fill stays inside the focused sign-in popup, including Google login windows.
- Reviewed Claude and standard Microsoft and Google native OAuth callbacks ask before opening the installed application, preserve the exact callback through redirects and popup closure, and show a useful error when no handler is available.
- Unknown application schemes remain blocked, and callback secrets never appear in confirmation prompts or persistent browser data.
