# Blanc 1.32.0

## Added

- Bring your Spaces over from Arc. In **Bring Your Tabs** (type
  `/bring-tabs` in the ⌘L or Ctrl+L panel), the new Arc option reads Arc's
  sidebar and brings each Space you pick, with its pinned tabs, its Today tabs
  and its folders, which become tab groups. With Blanc Patron, each Arc Space
  becomes a space in Blanc Spaces; without it, each Space opens in its own
  window. Tabs load only when you open them. You can also add Arc's top-row
  Favorites to a Favorites folder named **Arc**. Sign-ins, passwords,
  history, archived tabs, Notes and Easels stay in Arc, and Blanc only reads
  Arc's sidebar file without changing it. Arc never came to Linux: there, copy
  `StorableSidebar.json` from your Mac or PC and choose it with
  **Choose file…**.
- Blanc's interface is available in German, Spanish, French and Portuguese
  (Brazil), machine-translated. If your system uses one of these languages,
  Blanc now follows it (any Portuguese system gets Brazilian Portuguese);
  choose English or another language any time in Settings → General →
  Language.

## Changed

- Named Workspaces is now called **Blanc Spaces**, and each saved set of tabs
  is a space. Type `/space` in the ⌘L or Ctrl+L panel to switch to a space or
  save the current window as one; `/workspace` still works. Creating spaces is
  still part of Blanc Patron.
- When 1Password login fill isn't set up yet, the prompt's **Open Settings**
  button now opens Settings at the 1Password card instead of at the top.
- Blanc's website is now **blanc.day**. Settings → Help, the About window, the
  welcome screen's privacy link and the update error messages point there.
  Older blancbrowser.com links still work.

## Fixed

- On Windows and Linux, the keyboard shortcuts sheet showed "Search &&
  Commands". It now reads "Search & Commands".
- Opening Blanc while it's already running, for example by opening a link from
  another app, now just passes the link to the open Blanc. The second launch
  used to keep starting up in the background on the same profile and then
  fail.
