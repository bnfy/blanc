# Blanc 1.29.0

## Added

- Settings has a new **About & Trust** section. It shows facts about the
  installed build, checked on your device: the version, the Electron and
  Chromium versions, the blocker's filter sources and, on macOS and Windows,
  the app's code signature. It links to the release, the verification guide,
  the software bill of materials and the build provenance, and can export
  diagnostics. Opening it makes no network request.
- Intel Macs get every release again. Each release now ships both an Apple
  Silicon and an Intel build.

## Changed

- Blanc saves its settings, Favorites, history and workspaces in the
  background instead of pausing the app while it writes to disk. Quitting
  still saves everything before Blanc closes.
- In a Flatpak, Check for Updates says that Flatpak keeps Blanc current
  instead of showing an unsupported-channel warning.

## Fixed

- With uBlock Origin selected, uBO now restarts on its own if it fails while
  you browse. Pages wait while it restarts instead of loading unfiltered, and
  the shield shows that it is restarting. After three restarts in 10 minutes,
  Blanc offers to restart it for you instead.
- With uBlock Origin selected, a moment when Blanc itself was busy no longer
  counts against uBO's time to decide on a request, so pages stop failing
  after a brief freeze.
- On macOS, changing a setting no longer briefly freezes Blanc while it
  reloads the Dock icon.
- On Linux under Wayland, Settings and other sheets appear every time you open
  them, not only the first time, and the page underneath keeps responding.
- On Linux under Wayland, each permission prompt shows its own question
  instead of the previous one.
