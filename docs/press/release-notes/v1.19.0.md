# Blanc 1.19.0

## Improved

- **Choose Blanc as your default browser.** macOS now recognizes Blanc's web browser role in System Settings. On Windows, the installer registers Blanc as a browser candidate and the Make default button opens Default apps, where you make the final choice. Linux desktop environments can also offer Blanc for web links. Availability in each system's picker depends on its desktop settings.
- On macOS, an existing HTML document opened with Blanc from Finder opens in a tab.
- Updated to Electron 44.4.3, which retains Chromium 152.0.7977.130 and includes upstream fixes.

## Fixed

- Windows checks the system's chosen handlers for both HTTP and HTTPS before saying Blanc is the default browser. Opening Default apps alone no longer makes Blanc report that it is the default.
