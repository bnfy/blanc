# Blanc 1.13.0

## Added

- **Frequently visited sites** make Billboard useful automatically from local browsing history. Ranking and favicon artwork stay on the device, private tabs receive no history-derived row, and each tile can be hidden without deleting history.

## Updated

- **Inter start pages** replace the remaining monospaced typography across Ledger, Billboard, Shelf, Tally, Mahjong, onboarding, and the shared footer.
- **Sunrise branding** now carries across Blanc's supported platforms and public brand surfaces, with a Windows-specific icon treatment for clearer small taskbar sizes.
- **Simpler macOS icon choices** retain Sunrise, Sunrise Dark, Paper, and Ink while retiring the other legacy variants.
- **One-time presentation reset** moves every existing profile to Sunrise and Billboard for this release. Users can change either setting afterward, and those choices remain preserved across future updates.

## Fixed

- A populated Billboard remains readable and scrollable at Blanc's minimum supported window size instead of pushing its date above the viewport.
