# Blanc 1.45.1

## Changed

- In the Spaces menu, a shared Space's sync status now sits on its own line
  under the Space's name, so a long name is no longer cut short.

## Fixed

- With Shared Spaces on, the Spaces menu no longer keeps saying "Sync is
  busy; retrying." or marks shared Spaces "Waiting to upload" during routine
  sync. They now appear only when sync is actually being held back or a
  Space has changes it hasn't uploaded yet.
- With **Also for links I open in a new tab** on, a link you open in the
  background (middle-click, ⌘-click or Ctrl-click) whose rule needs a new
  window now opens that window behind the one you're using, instead of in
  front.
