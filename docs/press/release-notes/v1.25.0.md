# Blanc 1.25.0

## Fixed

- The folder picker opened by **move ▸** in Favorites now stays above neighboring rows, opens upward when needed, and stays inside the window. With many folders, its options scroll inside the menu while the **new folder…** field remains visible. Opening the picker no longer scrolls the selected favorite out of view.
- Escape closes the folder picker and returns focus to its move button; a second Escape closes Favorites.

## Refined

- Favorites group headings now use plain labels and count badges, without the curved bottom divider.

## Verify the download

- Authenticate `SHA256SUMS` with its Sigstore bundle using the certificate identity `anthony@bnfy.me` and OIDC issuer `https://github.com/login/oauth`. The same values are published on [Blanc's security page](https://blancbrowser.com/features/security).
