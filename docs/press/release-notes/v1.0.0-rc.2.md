# Blanc 1.0.0-rc.2

This is Blanc 1.0's second signed Apple Silicon release candidate for active
testing and review. It is a prerelease and does not replace the current Stable
update for existing users.

## New since rc.1

- **A right-click menu on the command bar.** The Island's address input now
  offers Undo, Redo, Cut, Copy, Paste, Delete, and Select All, plus two
  Blanc-specific actions: **Copy Clean Link** copies the visible address with
  known tracking parameters removed (`utm_*` and common click identifiers,
  matched case-insensitively and after percent-decoding, with every surviving
  parameter kept byte-for-byte in its original order), and **Paste and Go**
  navigates straight to the clipboard through the same pipeline as a typed
  address — including OS hand-off for `mailto:`-style links and
  search-vs-address detection — then closes the Island.
- **View Page Source.** Right-clicking a page's background now offers View
  Page Source, opening Chromium's own syntax-highlighted source view in a new
  tab so Back never loses your place.

## What to try

- **The Island.** Press Command-L to search, switch among tabs, find Favorites
  and history, reach tabs shared by another device, or run slash commands.
  Right-click the address field for the new menu.
- **Optional vertical tabs.** Choose **View → Tab Layout → Vertical Tabs** or
  Settings → General → Tab layout. Switching layouts does not reload open
  pages.
- **Named groups and private tabs.** Groups stay name-based rather than
  color-coded. Private tabs use a separate, non-persistent in-memory session
  and stay out of Blanc history, session restore, and reopen-closed.
- **Built-in blocking.** EasyList and EasyPrivacy filtering runs at the browser
  session layer rather than through an extension.

## Availability and boundaries

- This candidate is for **macOS on Apple Silicon only**.
- The command-bar menu is pointer-invoked on macOS; Copy Clean Link and Paste
  and Go have no keyboard-only path there yet.
- Blanc has no extension runtime or password import.
- Ad and tracker blocking is best effort.
- Profile Sync is optional and end-to-end encrypted; open-tab sharing is a
  separate, off-by-default per-device snapshot.
