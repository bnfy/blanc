# Blanc 1.12.0

## Added

- **Call audio buffering** adds Automatic, Stable, and Resilient receive-buffer choices for WebRTC calls. Stable targets about 400 ms for smoother speech, while Resilient targets about 1 second for severe crackling or chopped audio at the cost of slower conversation.
- **Sunrise app icon** becomes Blanc's default on macOS, with an appearance-aware light variant and a separately selectable Sunrise Dark variant.
- **Billboard start page** becomes the default layout for new profiles. Existing layout choices remain unchanged.

## Fixed

- Reopening Blanc from the Dock after closing every browser window no longer leaves a blank macOS window.

## Updated

- Electron is updated from 44.1.0 to 44.1.1.
