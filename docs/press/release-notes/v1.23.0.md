# Blanc 1.23.0

## Improved

- Settings, Favorites, History, Downloads, Shortcuts, and Bring Your Tabs now share a clearer Sunrise sheet design. Roomier cards, easier-to-scan headings, and controls that fit the minimum window size make everyday tasks less cramped.
- History groups visits by day, shows site icons, and lines up visit times. Favorites shows saved site icons or a domain-initial tile when no icon is available.
- Downloads lines up status and actions across rows, identifies the source site, and keeps the extension visible on long filenames.
- Privacy & Security settings are grouped by topic. Longer explanations can be expanded with **More** without losing any of their detail.
- The moving-in checklist and welcome tour are easier to use in a small window or at increased zoom.

## Fixed

- A site permission request no longer takes keyboard focus away from the page or an open Island panel.
- The Settings section marker now follows scrolling, and Shortcuts shows readable key labels instead of raw accelerator names.
- Mahjong's completion screen has two clear next steps. **Play Another** starts a fresh deal with the current layout and rules.
