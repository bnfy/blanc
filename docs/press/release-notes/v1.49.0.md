# Blanc 1.49.0

## Added

- **Mahjong tile sets.** Mahjong now has three tile sets, Porcelain, Carved
  and Inlay, and moves to the next one after every three boards you clear in
  a row. A board keeps the set it was dealt in. Starting a new game partway
  through a board you've played on starts the count again.
- **Mahjong celebrations.** Matching two tiles draws a short trail between
  them, and clearing a board plays a short celebration before the results
  card. A click or any key skips straight to the card. With reduced motion
  on, matched tiles glow briefly in place instead.

## Changed

- Mahjong takes on Blanc's Sunrise look, and on wide windows the Burst rack
  sits beside the board.
- Screen readers now name Mahjong's wind and dragon tiles plainly, such as
  "north wind" or "red dragon".
