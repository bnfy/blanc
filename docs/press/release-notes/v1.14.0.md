# Blanc 1.14.0

## Added

- **Faster new tabs** add a quiet Plus shortcut beside the Island's slash-command keycap. It opens one regular, ungrouped tab and puts the address field immediately in focus.

## Updated

- **A calmer resting Island** adopts the website navigation's compact 44px geometry, material surface, and shorter shadow while keeping the existing controls and unified proximity response.
- **Inter vertical tabs** replace the remaining monospaced labels across the rail, including section headings, groups, private markers, and the New tab row.

## Fixed

- Vertical-tabs mode no longer reserves an empty shortcut gap when both Island keycaps are hidden on a page.
