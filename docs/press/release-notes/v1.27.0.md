# Blanc 1.27.0

## Added

- Optional full uBlock Origin 1.75.0 on Apple Silicon and native Intel Macs,
  Windows x64, and Linux x64. Click the Island shield, choose your blocker,
  then use **Restart Blanc** to apply the change.
- Blanc styling for uBO’s popup and Dashboard, with filter subscriptions,
  custom filters, dynamic rules, picker/zapper, logger, and backup/restore.
  Filter lists can update automatically; executable resources stay pinned to
  reviewed Blanc releases.
- Separate uBO configuration for each regular profile. Blanc Blocker remains
  the default and protects private tabs; the two blockers keep separate site
  exceptions. Provider selection and uBO configuration stay outside Profile
  Sync. General extension-store support is not included.
- Automatic return to Blanc Blocker with an explanation if saved uBO selection
  is unavailable in the running build, preserving uBO configuration. Intel
  builds running under Rosetta use Blanc Blocker. An available uBO instance
  that crashes or exceeds its request deadline keeps traffic blocked until
  recovery or an explicit user choice.

## Fixed

- Provider restart and shutdown no longer lose an overlay callback when
  Electron removes a native child view.
- Linux AppImage provider restarts use the upstream extraction launcher and
  retain Chromium sandbox enforcement. Normal close/relaunch preserves the
  selected blocker and saved uBO filters.
- The Linux sandbox refusal dialog offers **Open Setup Guide** and **Quit**.
  X11 retains **Copy Link**; Wayland omits clipboard controls. A relaunch with
  the guide URL omits Open Setup Guide to prevent a loop. Sandbox requirements
  and system security settings are unchanged.
