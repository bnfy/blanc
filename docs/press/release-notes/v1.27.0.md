# Blanc 1.27.0 — candidate notes

**Draft. Not published and not approved for public copy.** The current public
release remains v1.26.0. Final notes and the supported platform list depend on
signed installed-candidate acceptance and the release protocol.

## Candidate changes

- Optional full uBlock Origin 1.75.0 provider, with separate profile configuration
  on Apple Silicon macOS and Windows x64, and a blocker chooser accessed from
  the Island shield. Provider changes require
  restart; the chooser offers an immediate restart when required.
- Blanc presentation for uBO's original popup and Dashboard tools, retaining the
  approved Sunrise artwork and native filtering controls.
- Blanc Blocker remains the default and protects private tabs. uBO keeps separate
  site exceptions and data for regular profiles.
- A selected uBO provider unavailable in the running build starts Blanc Blocker
  with an explanation and preserves the saved uBO configuration. Runtime uBO
  failures retain explicit recovery controls and the fail-closed request policy.

- Intel macOS and Linux keep Blanc Blocker while signed installed uBO acceptance
  is completed for those platforms.
- Fix a production overlay blur callback that could interrupt provider restart
  or app shutdown while Electron removed a native child view.

- The Linux sandbox refusal dialog offers **Open Setup Guide** and **Quit**.
  X11 also retains **Copy Link**; Wayland omits clipboard controls. A relaunch
  with the guide URL omits Open Setup Guide to prevent a loop. Sandbox
  requirements and system security settings are unchanged (merged PR #494).
