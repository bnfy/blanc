# Blanc 1.50.0

## Added

- **Folders inside folders, in the order you choose.** Favorites
  (Show Favorites, ⌥⌘B or Ctrl+Shift+O) now opens a manager with your folders
  in a sidebar. Make folders inside folders, drag favorites and folders where
  you want them, select several at once, and search every folder. Deleting a
  folder keeps what was in it. Importing from another browser keeps folders
  inside folders in the browser's order (empty folders aren't brought over,
  and very long folder paths are shortened), and one **Bring my stuff to
  Blanc** button now handles importing favorites and open tabs. The Favorites
  menu shows the same folders, and `/save` takes a path, such as
  `/save Work > Clients`. On the iPhone, a folder inside a folder shows as one
  folder named by its path for now.
- **Websites ask before reaching your device or local network.** The first
  time a website tries to connect to an app on this device or to a device on
  your local network, such as a router or printer, Blanc asks. Your answer is
  remembered for that site and listed in Settings → Site permissions, where
  you can remove it. Private tabs forget it when Blanc quits.

## Changed

- **Downloads save straight to your Downloads folder.** Blanc no longer asks
  where to save each file you download; a file with the same name as one
  already there gets a number added. Downloads a page starts without your
  click, and **Save Image As…**, still ask. To be asked every time, turn on
  **Ask where to save each file** in Settings → General (#1591).

## Fixed

- Sign-in pages that check for permission before talking to an app on your
  computer, such as Okta's for Okta Verify, now get Blanc's prompt instead of
  being turned away (#1585).
