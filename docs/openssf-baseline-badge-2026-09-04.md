# OpenSSF Baseline badge website claim

Initially verified September 4, 2026 at Level 1 and updated September 13, 2026
against Blanc's public
[OpenSSF Baseline Level 2 assessment](https://www.bestpractices.dev/en/projects/14451/baseline-2).
The assessment reports all 24 Level 1 controls and all 19 Level 2 controls met
and awards the Baseline Level 2 badge under baseline version 2026.08.28.

The website describes this result as a **self-assessment** and links directly
to the public record. It does not describe the badge as a security
certification or an independent audit.

`site/public/openssf-baseline-2.svg` is an exact snapshot of the badge returned
by the official project badge endpoint on that date. It appears in the
Security feature page's assessment block and, since October 19, 2026, in the
"Evidence you can inspect" card at the top of Privacy & Security (`/trust`),
so the page the header links to shows it without opening a section. Serving the snapshot locally avoids a
third-party request; its link still opens the live assessment so visitors can
check its current state.
