# Custom product pages

The rendered screenshots of Blanc for iPhone's custom product pages, one
folder each: `6.9/` (1320 × 2868) and `6.3/` (1206 × 2622). The record
(audiences, promotional text, claims and the App Store Connect steps) is
the *Custom product pages* section of
[`../../app-store-listing.md`](../../app-store-listing.md).

They're designed on the same Claude Design canvas as the default page,
**Blanc for iPhone App Store Screenshots**, one canvas page each ("Custom
page · …", page id `cpp-<folder>`), and copied into `../design/project/`
with the rest. Each is a shorter path through the default page's design: the
same real captures, frames and Blubird captions, and the same sky at each
position, dawn on the first shot and day on the last. Change them there and
re-render as `../design/README.md` says; `npm run ios:app-store-screenshots
-- --compose` writes these folders along with the default sets.
