## Result meanings

- **pass:** direct execution evidence covers the stated scenario on the named release and platform.
- **partial:** the notes state exactly what was checked and what remains untested.
- **unsupported:** Blanc does not provide the capability.
- **blocked:** the check could not complete for a recorded external or environmental reason.
- **not-run:** no applicable current-release execution result has been recorded. Its date is the evidence-review date, not a test date.
