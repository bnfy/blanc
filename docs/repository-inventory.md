## Binary review

A tracked-file MIME review found no checked-in native executable, shared
library, WebAssembly module, Electron native addon, or application archive.
Apart from images/media and text formats, the review identified:

- `build/embedded.provisionprofile`: Apple-signed CMS provisioning data for
  the app's restricted entitlement. Its plist can be inspected using
  `security cms -D -i build/embedded.provisionprofile`. Packaging checks in
  `scripts/preflight-mac-signing.mjs` and `scripts/after-sign-verify.js` validate
  the profile, certificate relationship and packaged result.
- `src/main/assets/adblock-engine-seed.bin`: a serialized blocker engine
  generated by `adblock/seed.mjs` from pinned filter inputs and dependency
  resources. Use the documented blocker build/check commands to regenerate
  and verify it. Its serialized resource content requires source-level review;
  a file-type scan alone does not establish that it contains no executable
  material.
- `src/renderer/pages/inter-latin.woff2` and
  `src/renderer/pages/jetbrains-mono-latin.woff2`: font assets covered by the
  recorded upstream notices and OFL license texts.

Generated application installers belong in GitHub Releases, rather than the
source tree. This record does not mark the OpenSSF generated-executable or
reviewable-binary criteria satisfied: the blocker seed's treatment must be
resolved against their exact definitions. Nor does it prove a complete
multi-repository inventory. Recheck the inventory when adding a codebase or
binary asset.
