# v1.21.0 window geometry and Sunrise release — 2026-09-21

Status: complete. v1.21.0 is public, the canonical website is deployed, and
both adjacent desktop updater handoffs are confirmed.

Release PR: <https://github.com/bnfy/blanc/pull/411>.

## Scope

- Remember each Blanc window's normal bounds and maximized or fullscreen state
  across app launches on macOS, Windows, and Linux.
- Forget the native geometry entry when a secondary window is explicitly closed,
  so that window does not reappear during later session restoration.
- Apply the Sunrise visual system and Newsreader invitation typography across
  the four start-page layouts.
- Prevent websites and service workers from setting Blanc's operating-system
  application badge.
- Advance the application version to 1.21.0 and the macOS bundle build number
  to 1210. Electron remains at the current 44.4.3 release.

## Owner waiver

The owner did not manually install and exercise the private Windows and Linux
candidates. Before merge and release, the agent identified the missing checks:

- normal bounds and maximized/fullscreen state surviving quit and reopen;
- an explicitly closed secondary window staying closed; and
- closing the last visible window terminating Blanc before a successful
  relaunch.

The agent stated that publishing without those checks risks shipping packaged
Windows or Linux window-state behavior that differs from the native CI smoke,
including restored geometry/display-mode failures, a secondary window returning
after explicit closure, or a hidden-window/process lifecycle regression. On
2026-09-21 the owner explicitly replied **“waive”**, accepting that risk and
authorizing the release to proceed without the manual Windows/Linux candidate
checks. Automated candidate and CI evidence remains required and passed; this
waiver does not waive signing, notarization, authenticated-manifest, public
download, exact-tag smoke, website, or updater-handoff gates.
