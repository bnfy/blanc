# Blanc v1.30.0 release — October 7, 2026

Status: published and independently verified; public v1.30.0 is the baseline.
The adjacent public-feed updater handoffs (v1.29.0 → v1.30.0) on macOS and on
the Windows VM's normal install are pending owner confirmation.

Scope: drag to reorder tabs and groups in the expanded Island and in vertical
tabs, with Alt/Option+Shift+Up/Down keyboard moves (#619). The other changes
merged since v1.29.0 are dev-dependency bumps, CI, documentation and the
v1.29.0 records; the `fast-uri` patch (#617) is dev-only and does not ship in
the app. Release notes: [v1.30.0](../press/release-notes/v1.30.0.md). Stable
mode, platforms `mac,windows,linux`, `BLANC_MAC_ARCHES=arm64,x64`, from
`5be79e58d08ca9bcf7cb99b3d8f84c21c654b1c7` (PR #621).

- PR #619 passed all 21 completed check runs on its head SHA (two conditional
  jobs skipped), including the desktop acceptance suites on macOS (Apple
  Silicon and Intel), Windows and Ubuntu that drive the new drag scenarios

- No hands-on Windows or Linux check of the drag feature was run before

  move that check to after release; it remains pending.
- PR #621 (release prep) passed all 22 completed check runs on its head SHA

  --audit-level=high` reported 0 vulnerabilities.
