# Blanc v1.31.0 release — October 9, 2026

Status: published and independently verified; public v1.31.0 is the baseline.
The owner confirmed both adjacent public-feed updater handoffs (v1.30.1 →
v1.31.0), on macOS and on Windows.

Scope: a minor release with these app changes merged since v1.30.1.

- Start page footer rework and centered Billboard (#667): the moving-in
  checklist becomes a Finish setup pill with a popover, the Patron reminder
  becomes one footer pill whose × hides it on the device for 90 days
  (`patronCalloutDismissedAt`, device-local), Customize is centered, Billboard
  content is centered vertically, and the clock drops the day period in every
  locale.
- The app's serif headings use the website's Newsreader Condensed build, and
  the Billboard clock weight drops from 650 to 500 (#666).
- Private-tab markers share one dashed style across the Island chip, the ⌘L
  rows and vertical tabs, and the private start page footer copy is shortened
  (#669).
- Bring Your Tabs shows every tab on its Tabs step (#670).
- First-day retention signals `day1_default` and `day1_browsed` (#671; the
  collector half, #668, was deployed earlier). The copy already said "Blanc
  1.31.0 and later" and the collector's `DAY_ONE_SIGNALS_MIN_VERSION` is
  1.31.0, so neither needed changing.
- The Island no longer blinks when opened by a click, and a stalled overlay
  frame pauses the expand instead of skipping ahead (#673).
- Interface localization Phase 1 (#672) ships its catalog, setting and
  guards with no user-visible change: English is the only selectable
  language and the Language setting stays hidden.

Release notes: [v1.31.0](../press/release-notes/v1.31.0.md). Stable mode,
platforms `mac,windows,linux`, `BLANC_MAC_ARCHES=arm64,x64`, from
`5bb0e0da01e05d612382fa99a434524ed2c5b108` (PR #674).

## Attempts

The release ran three times from the same commit. Neither stopped attempt
found a product bug, and neither reached the tag push, so no tag, draft or
asset existed until the third attempt.

1. **Press gate, desktop acceptance.** `The panel and rail dim quiet rows
   identically at rest` (`spec/acceptance/quiet-tabs.feature:77`) failed after
   Cucumber's retry: a panel row ancestor read opacity 0. Since #673 the ⌘L
   panel's contents start at opacity 0 and fade in from the second animation
   frame, so a read inside that window sees a transparent ancestor. The
   scenario passed alone, in the full `@F31` set (30 scenarios), and in a
   later full run (207 of 207). Another full run that day failed five
   different ad-blocking scenarios instead, all of which passed alone. These
   are test timing races; the quiet-tabs step should wait for the panel's
   fade to finish.
2. **Live favicon matrix.** After the gate, both notarized Mac builds, the
   packaged first-run, regression and Workspace smokes had passed, the
   additional 25-site matrix failed because `https://www.booking.com/` loaded
   with a `shortcut icon` link but no favicon on the tab. Rerunning Booking.com
   alone twice against the same signed build passed both times.
3. **Published.** The third run passed everything.

The owner directed afterwards that a failure which passes on rerun against
the same build must not restart the release: the release continues from the
failed step instead. `release.sh` has no resume mode yet.
