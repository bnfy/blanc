## Release contents

- The resting Island uses a 44px rendered height, 17px corner radius, 68px
  chrome strip, website-derived material surface, and shorter authoritative
  shadow while retaining the unified proximity rise and scale response.
- A quiet Plus keycap beside the slash-command keycap creates one regular,
  ungrouped tab and immediately focuses its address field. It is hidden when
  vertical tabs are active because the rail already has a New tab control.
- Vertical-tab labels, headings, groups, private markers, and the New tab row
  use Inter instead of JetBrains Mono.
- Vertical mode no longer reserves an empty Island shortcut gap when its
  redundant keycaps are hidden.
