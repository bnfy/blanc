## Release contents

- WebRTC calls gain Automatic, Stable, and Resilient receive-buffer choices.
  Stable targets about 400 ms; Resilient targets about one second and trades
  conversational latency for greater tolerance of chopped playback.
- Sunrise becomes the default macOS app icon, with an appearance-aware light
  variant and a separately selectable Sunrise Dark variant.
- Billboard becomes the default start-page layout for new profiles. Existing
  profile choices are unchanged.
- Reopening Blanc from the macOS Dock after closing every browser window no
  longer leaves a blank window.
- Electron advances from 44.1.0 to 44.1.1.

## Product evidence

- The original report was receive-side chopped audio in ChatGPT Voice inside
  Blanc while YouTube playback remained clean and the voice tab stayed active.
- During development, both Automatic and Stable initially still produced some
  crackling. After the implementation and rebuilt development instance, the
  user's final end-to-end ChatGPT Voice check reported **no crackling**.
- That check exercised the intended product surface and informed the release
  decision, but it ran in the rebuilt development instance. It is not described
  as an exact signed-candidate or installed-public-binary audio test.
