# v1.17.1 HTTP-authentication policy release — 2026-09-15

Status: public and deployed. Published at `2026-09-16T03:33:17Z` from immutable
source `7d3fe9ed7ec752950b91bc5b73a398bd40a3277b`. Public artifact, exact-tag
smoke, and canonical site deployment passed. Independent strict-deep-signature

Release: <https://github.com/bnfy/blanc/releases/tag/v1.17.1>.

## Scope

- Blanc no longer opens its own username/password window for HTTP Basic,
  Digest, subresource, or proxy authentication challenges. Website-provided
  sign-in pages and forms remain unchanged.
- Sites and proxies that depend on a browser-managed HTTP-authentication prompt
  no longer receive one; without a site-provided flow, access can fail with a
  401 or 407 response.
- Electron advanced within the existing 44.x line from 44.3.0 to 44.4.1. The
  macOS bundle build number advanced from 1170 to 1171.
- PR #288 was deliberately excluded. Its bounded-import and related hardening
  remains behind a separate affected-machine validation gate.
