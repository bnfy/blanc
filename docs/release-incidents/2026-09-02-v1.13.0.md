macOS/Windows updater handoffs remain required follow-ups.

## Release contents

- Billboard now ranks frequently visited sites from ordinary device-local
  history, keeps favicon artwork and hidden-tile choices local, and excludes
  private tabs from both contributing to and receiving the row.
- Every start-page template uses Inter instead of JetBrains Mono.
- Sunrise branding now carries across macOS, Windows, Linux, and public brand
  surfaces. Windows uses a dedicated small-size treatment for taskbar clarity.
- macOS Settings retains Sunrise, Sunrise Dark, Paper, and Ink, and removes the
  other retired icon variants and their obsolete paid-benefit messaging.
- Every existing profile receives one deliberate Sunrise/Billboard reset in
  this release. Changes made afterward remain preserved across future updates.
- A populated Billboard remains readable and scrollable at the minimum
  supported window size.
