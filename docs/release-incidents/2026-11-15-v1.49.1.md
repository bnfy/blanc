# Blanc v1.49.1 release — November 15, 2026

Status: published and independently verified at 18:47 UTC on November 15,
2026, from `673ff2eb052011b1efd14438a397a57d457de241`. The press gate ran on
the owner's Mac Studio rather than the release Mac. The release run stopped
after its tag and draft existed, because a packaged smoke check in the native
run timed out against this release's own New Tab reuse. The owner approved
fixing the smoke (test and workflow only, #1553 and #1555) and dispatching the
native builds again against the same tag; the rest of `release.sh` then ran by
hand in its own order. The owner reported the macOS and Windows updates from
v1.49.0 on November 15, 2026 (below).

## Scope

A bug-fix release on the same runtime as v1.49.0, castLabs' Electron for
Content Security `45.2.1+wvcus`. Checked on November 15, 2026, castLabs'
newest stable release was still `v45.2.1+wvcus`; the only newer one was the
`v46.0.0-alpha.7+wvcus` pre-release.

Release notes: [v1.49.1](../press/release-notes/v1.49.1.md), prepared in #1548
(merged at 14:14 UTC as `ec0018d3a`).

- **Changed:** New Tab (⌘T, Ctrl+T) and ⌘⇧N switch to an unused new tab in
  the window instead of opening another, with a Settings switch (#1505).
  With vertical tabs on a Mac, the Space mark has its own row below the
  window controls. Sunrise Spectrum and Sunrise Amber have a muted outline
  in Dark.
- **Fixed:** a page that fails to load is named after its site; the expanded
  Island no longer runs under the window controls in a narrow Mac window;
  the welcome walkthrough names `/allow-ads`; Settings capitalizes the Start
  Page layouts, and the Theme setting no longer names both systems.

**What's New:** none; bug-fix releases skip the page check.

**Release commit.** Three Blanc Beta (Chromium fork) commits landed on `main`
after #1548 (#1549, #1550, #1551). None touches the Electron app, its
lockfiles or its tests, but `release.sh` releases only exactly `origin/main`,
so the release commit is `673ff2eb0`, not `ec0018d3a`.

**Not checked before release** (open in
[unreleased.md](../press/release-notes/unreleased.md)): New Tab reuse by hand
in a packaged build on macOS, Windows and Linux.

## The release run

`npm run release` ran in a native Terminal.app window on the release Mac, from
a clean worktree detached at `673ff2eb0`, with `BLANC_RELEASE_OPERATOR=terminal`,
`BLANC_RELEASE_MODE=stable`, `BLANC_RELEASE_RUNTIME=ecs`,
`BLANC_RELEASE_PLATFORMS=mac,windows,linux` and `BLANC_MAC_ARCHES=arm64,x64`.
The signing identity was typed into the window by the owner. The
`==> Preparing` line read `runtime=ecs`.

1. `op signin` went through the 1Password desktop integration, the press gate
   passed from the ledger, and both notarized Mac builds were made.
2. Every packaged check passed on the signed build, including public ECS
   acceptance (installed uBO, file isolation, and protected playback with
   `passed: true` on arm64, `PLATFORM_SOFTWARE_VERIFIED`, the CDM in a
   sandboxed `Blanc Helper (Plugin)`).
3. The tag `v1.49.1` was pushed and the authenticated draft created with the
   complete macOS asset set.
4. Native run
   [`43742162887`](https://github.com/bnfy/blanc/actions/runs/43742162887)
   was dispatched. Its `linux` job failed at **Packaged browser and Settings
   regressions**: `packaged-browser-compatibility-smoke.mjs` timed out
   `waiting for typed packaged tab`. Its `windows` job reached the
   `ecs-signing` gate and was not approved, because it runs the same smoke.

**Cause.** The smoke launches Blanc with a link, which opens an unused New Tab
page beside the link's tab, then asks for a new tab and waits for the count
to rise by one. With New Tab reuse (#1505), on by default in 1.49.1,
`openOrReuseNewTab` switches to that unused page instead. The last state the
smoke saw shows exactly that: still two tabs, the active one the launch's New
Tab page. The app behaved as designed; the smoke predates the feature, and
#1547 had turned reuse off only for the acceptance suite. The Mac release
path doesn't run this smoke. The unchanged smoke failed the same way, at the
same line, on the signed 1.49.1 Mac build.

## Recovery

With the tag in place, the release could not be rerun. The owner approved the
plan below.

1. Run `43742162887` was cancelled; `release.sh` printed `Native build failed.
   Draft remains unpublished.` and exited 1. The tag and draft stayed as
   evidence; neither was deleted or overwritten.
2. **#1553** (merged 18:14 UTC as `fffbb3d25`) starts the smoke with
   `reuseNewTab: false`. On the signed 1.49.1 Mac build the unchanged smoke
   failed and the changed one passed.
3. Run [`43745795384`](https://github.com/bnfy/blanc/actions/runs/43745795384),
   dispatched against the tag with `release.sh`'s own arguments
   (`mode=release`, `runtime=ecs`, `source_sha=673ff2eb0`, `platform=all`),
   failed the same way on Linux and Windows. The workflow builds from the tag
   and takes only a fixed list of smoke files from the workflow commit
   (**Load smoke harness from workflow commit**), and this smoke wasn't on it.
4. **#1555** (merged 18:36 UTC as `d708a6c0c`) adds the smoke to both lists.
   Between the tag and `d708a6c0c`, the only workflow, test or script changes
   are these two.
5. Run [`43747728959`](https://github.com/bnfy/blanc/actions/runs/43747728959)
   passed: `linux`, `windows` and `linux-legacy-launch`, with the same skipped
   jobs as v1.49.0's run. Its `ecs-signing` gate was approved on the owner's
   standing release approval.
6. The remaining `release.sh` stages ran by hand from a visible Terminal
   window in the release worktree, from a script that copies lines 645–696 of
   `release.sh` at the tag verbatim. It first checked that HEAD was the tag,
   the tree clean, the release still a draft, and run `43747728959` the green
   `Release v1.49.1 (all)` run. Then: the draft download, manifest validation
   (15 artifacts), the SBOM and `SHA256SUMS`, the What's New check, the
   Sigstore sign-in in Safari, `cosign verify-blob` against the pinned
   identity (`Verified OK`), the complete manifest check (17 artifacts),
   upload of the three derived files, publication at 18:47 UTC, the
   logged-out download smoke, and the changelog refresh. It exited 0.
