# Blanc v1.40.0 release — October 20, 2026

Status: published and independently verified; public v1.40.0 is the baseline.
It published on the second attempt. The first stopped in the press gate,
before any tag or draft, on a test-hook focus reading fixed by #1011 (below).
The What's New page was live before the release started, as the gate added
after v1.39.0 requires. The macOS and Windows updater handoffs, and the
packaged and Windows/Linux hand checks of the new features, are pending.

## Scope

A minor release with these app changes merged since v1.39.0.

- **Split View (F53; #993, #997, #1001, #1004, #1005).** Two tabs side by
  side in one window, kept as one item: a tab's **Split with ▸** menu
  (grouped by tab group since #1005) or **Keep as split** on a Glance card
  makes one. Each pane is a rounded card with a 1 px border, darker on the
  focused pane, with a corner tab showing its site and a ×. The focused pane
  is the window's current tab, so the Island, Back and Reload follow it. The
  divider resizes the panes. Splits persist in `session.json` v2 windows and
  Spaces (never in the flat rollback mirror, never synced; private tabs are
  never saved), and Close Split is one Recently closed entry. Two panes only
  in this release. Spec `docs/superpowers/specs/2026-10-19-split-view-design.md`.
- **Floating Glance (F34; #1007, #1008).** Glance is now a card floating over
  the current page instead of a side-by-side pane: centered at
  `min(1100 px, 80%)` of the page area, movable by its header, resizable from
  an 8 px ring (360 × 280 minimum), reset by double-clicking the header, and
  remembered per device (`glanceFrame`). The page behind stays usable. A tab
  switch closes it; Open as tab makes the Glance page current; Escape closes
  it only from the card's chrome. #1008 saves the frame whichever way a
  Glance ends (and on quit), holds a window's first card until it has drawn,
  announces Open as tab and Keep as split once, and keeps the card still
  during a push-style Island reveal. Spec
  `docs/superpowers/specs/2026-10-20-floating-glance-design.md`.
- **Auto-hide, float style (#994, #999, #1002, #1003).** With Auto-hide on,
  the revealed Island now floats over the page by default; Settings →
  General → **When the Island comes back** keeps **Push the page down** as a
  choice (device-local `islandAutoHideStyle`). While floating, the Island
  reveals only from the top edge (or ⌘L) and hides once the pointer moves into
  the page, and the window buttons hide and come back with it on every
  platform. On Linux a covered strip keeps one row uncovered so the floating
  views follow resizes (#999). Spec
  `docs/superpowers/specs/2026-10-20-floating-island-design.md`, D29.
- **Fixes:** the address field is ready after closing a window's last tab
  (#1000); dark and private tabs load on a dark background (#991).

## The release run

**Attempt 1 (no tag, no draft).** It stopped in `test:acceptance:desktop` on
one scenario after its retry: "Close Tab with focus in the reference closes
the reference tab only" (`{"os":false,"recorded":true,"windowFocused":true}`).
The same scenario had failed once in the full run for #1008 and passed alone
four times.

- The `@F34` subset reproduced a sibling focus failure 4 of 4 times.
- Two suspects were ruled out. Turning off #1008's first-open hold didn't
  change it, and #1007's commit (`24472f7d`) failed the same way, although
  that commit had passed earlier in the day. A stray test Electron (orphaned
  by a stopped run) was also found and killed; the failure stayed.
- Logging showed the Glance page really held focus (`isFocused()` true,
  visible). But `webContents.getFocusedWebContents()`, which the test hook's
  `focusedWebContentsId()` used, returned a different, awake, inactive
  `blanc://newtab` tab view that also still reported `isFocused()`.
- #1011 makes the hook ask the focused window's on-screen contents first.
  With it, `@F34` passed 69/69 and the full runnable suite 467/467.
- The one product use of the same call, the permission prompt's focus
  hand-back on first attach, is fixed separately in #1012. It is not part of
  this release.

**Attempt 2** ran from `17ed2205` after #1011 merged. Every gate passed:

- **Press gate:** 4,143 unit tests, and 467 desktop scenarios with 3,096
  steps.
- **Builds:** the macOS identity and profile preflight, then both notarized
  builds.
- **Packaged checks:** fuses, byte-identical blocker payloads, compliance
  payloads, first run, release regressions, Workspace quit/restart, both live
  favicon matrices, and migration from public v1.39.0.
- **Native build:** the tag and draft were created, then native run
  `39537906281` (03:19–03:26 UTC on October 21) built and signed Windows and
  Linux.

The Sigstore loopback page in Safari completed on the first try; the bundle
verified. The draft was published at 03:27:16 UTC on October 21 (23:27 EDT on
the 20th), the logged-out download smoke passed, and
`site/src/data/releases.json` was refreshed.
