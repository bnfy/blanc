## Scope

The release refines Blanc's optional macOS 1Password integration. A small
Blanc-styled hint may appear when the visible page contains a current-password
field, using bounded device-local structure-only page metadata. The hint does
not inspect field values or page text, contact 1Password, or fill
automatically. Settings can save an email address or account ID and explicitly
ask the installed 1Password app to verify it. Credential lookup and fill remain
explicit user actions.
