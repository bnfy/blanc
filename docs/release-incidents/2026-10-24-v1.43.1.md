# Blanc v1.43.1 release — October 24, 2026

Status: published and independently verified; public v1.43.1 is the baseline.
It published on the second attempt; the first stopped in the press gate,
before any tag. No What's New page: bug-fix releases skip that gate. It
restores Linux updates and downloads, which were held at 1.42.1 after
[v1.43.0](2026-10-24-v1.43.0.md) didn't start on glibc older than 2.38. The
owner confirmed the macOS and Windows updater handoffs.

## Scope

- **Fix: Linux natives for glibc 2.28 (#1086).** The DRM launcher is linked
  statically and the CDM preload is built in the pinned
  `quay.io/pypa/manylinux_2_28_x86_64` image (by digest, no network inside
  the build). `scripts/linux-native-build.cjs` reads each binary with
  `readelf` in packaging and fails the build if it would not start on glibc
  2.28. The native release workflow now hands the built AppImage to a
  `linux-legacy-launch` job on Ubuntu 22.04, which must launch it before the
  upload and provenance steps run.
- Release notes wording (#1089, owner-approved): dropped a claim that
  protected video plays on Ubuntu 22.04 (only launching was tested there; DRM
  playback was tested on Ubuntu 24.04), and asked anyone who downloaded the
  1.43.0 AppImage to download again.

Before the release, one Linux public-ECS validation on the #1086 merge
(`6f87badbe`, run `40100772032`) passed both the build, with packaged DRM
playback, and the Ubuntu 22.04 launch. Locally, in Docker, the released
1.43.0 launcher failed on Ubuntu 22.04 and Debian 10, while the static
launcher ran and the manylinux preload loaded on both.

Release notes: [v1.43.1](../press/release-notes/v1.43.1.md) (prep #1086).
Stable mode, platforms `mac,windows,linux`, `BLANC_MAC_ARCHES=arm64,x64`,
`BLANC_RELEASE_RUNTIME=ecs`, from `154d1db84a7d54d83b6dd40ef91ea7042636446f`.
Packaged files changed since v1.43.0 only in the Linux native build scripts,
the release workflow and the version. `build.mac.bundleVersion` is **1431**.

## The release runs

Both attempts ran from `154d1db84`.

- **Attempt 1** stopped in the press gate's desktop acceptance run: 474 of
  478 scenarios passed. "The card stays put while a pushed Island slides in"
  (`glance.feature:538`) and three Island auto-hide scenarios
  (`island-and-commands.feature:140`, `:180`, `:190`) timed out after two
  attempts; the load average was about 4.9 and Low Power Mode was off. Run
  alone in the same checkout, they passed. Treated as load, and rerun.
- **Attempt 2** passed every gate, with the owner approving both 1Password
  prompts:
  - **Press gate:** 4,412 unit tests, and 478 desktop scenarios with 3,194
    steps.
  - **Builds:** both notarized ECS builds with castLabs VMP signing and the
    ECS release identity check.
  - **Packaged checks:** fuses, byte-identical blocker payloads, compliance
    payloads, first run and the public ECS acceptance.
  - **Native build:** the tag and draft were created, then native run
    `40105823451` built and signed Windows (its `ecs-signing` deployment
    approved under the owner's release approval) and built Linux, which
    passed `linux-legacy-launch` on Ubuntu 22.04 before upload.

The Sigstore loopback page in Safari completed on the first try. The bundle
verified, the draft was published at 15:21:12 UTC, the logged-out download
smoke passed, `site/src/data/releases.json` was refreshed, and the script
exited 0.

  Linux 1.42.1 installs update straight to 1.43.1. v1.43.0's removed
  `latest-linux.yml` stays removed.
