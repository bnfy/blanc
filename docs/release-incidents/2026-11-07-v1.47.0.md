# Blanc v1.47.0 release — November 7, 2026

Status: published and independently verified at 17:18 UTC on November 7, 2026
(12:18 pm in New York), from `988a9bf093d500af18f94235afbe4ab62ce79110`, on the
second attempt (the first stopped before the tag; the second resumed at the
failed step). The macOS and Windows updater handoffs from v1.46.0 are still
pending (below).

## Scope

The 1.47 feature release, and the first public release on Electron 45: castLabs'
Electron for Content Security `45.2.1+wvcus` (Chromium 156.0.8078.75),
published by castLabs on November 5, 2026 and still their newest ECS stable
release when this one shipped (their only newer tags were 45 alphas). It
replaces `44.9.3+wvcus` (Chromium 152.0.7977.167). `44.10.1+wvcus` was
qualified and merged first (#1399) but never released: 45.2.1 landed on `main`
(#1406) before the release started.

- The runtime's security review is in
  [the ECS runtime security review](../ecs-runtime-security-review-2026-10-23.md).
  The TLS probe passed on 45.2.1 (all four odd IP spellings rejected; recorded in that review). **R2, the
  native-source review, is waived by the owner for `45.2.1+wvcus` only, in
  writing on November 7, 2026 at 14:08 UTC. That is a waiver, not a pass.**
- Signed uBO acceptance for this pin: Apple Silicon (notarized `73992c725`,
  local), native Intel Mac (the same build, run `42379528773`), Windows x64
  (`42378362544`) and Linux x64 (`42378364429`). It applies only to those four
  platform records; Rosetta stays excluded.

Release notes: [v1.47.0](../press/release-notes/v1.47.0.md), prepared in #1412.

- **Added:**
  - Default page zoom (F62, #1401): Settings → General → Appearance, 50% to
    200%, with a size saved per site and listed in Settings.
- **Changed:**
  - ⌘+/⌘− step through Chrome's sizes, so zooming back always lands on 100%.
  - On Windows with Island auto-hide on, the drag band along the top of the page
    is 10 px instead of 6 (#1397).
  - The runtime is ECS 45.2.1 with Chromium 156.
- **Fixed:**
  - A shared Space arriving from another device while Blanc quit could overwrite
    `session.json` with an empty session (F57-15, #1405).

The release also carries the macOS update-restart change from #1405 (a packaged
update now closes windows the way Quit does). It is untested against a real
update (see the handoffs below).

## Before the release

- **What's New:** the owner chose no page for 1.47 (one headline feature), so
  `1.47` is in `noPage` in `site/src/data/whats-new.json` (#1414) and
  `release.sh` skips its check.
- **Press gate:** `npm run release:prepare` passed every stage on the release
  commit before the release started, with acceptance at 604 of 604 in one
  attempt (below).
- **castLabs check:** the newest ECS release was `v45.2.1+wvcus`, the pinned
  one, on the day (repeated before signing).
- **Hand checks**, on a Developer ID-signed, VMP-signed ECS 45.2.1 qualification
  build of the release commit (`npm run dist:ecs:dir -- --arm64`) with a
  scratch profile; the notarized release build was not the one tried by hand:
  - **Default page zoom, Apple Silicon:** 15 of 15 checks passed with real ⌘= and
    ⌘0 key presses (default reaches open and new tabs; ⌘= steps 75% to 80%;
    tabs on the site follow and the other site doesn't; Settings lists the site;
    Chromium's `Preferences` holds no zoom for it; the size survives a relaunch;
    ⌘0 returns the site to the default and Settings drops it).
  - **Spotify and Netflix playback:** the owner played both; both worked.
  - **Passkeys:** the owner registered and signed in with a passkey at
    webauthn.io with Touch ID; it worked.
  - **1Password fill:** the owner got "No login form found" on a real page that
    fails the same way in the installed v1.46.0, so it isn't a regression. The
    fill code is unchanged since v1.46.0, and four local login forms were found
    in the packaged 45.2.1 build. It reads only the top document's visible
    inputs; forms in iframes, shadow DOM or hidden behind a button are not
    found. The site was never named.
  - **Not checked:** page zoom in a packaged ECS build on Windows and Linux (the
    F62 acceptance scenarios passed on both in CI for the prep commit, but
    unpackaged); zoom's PDF, private-tab, sign-in popup and second-profile cases
    in a packaged build. The owner accepted starting the release without the
    packaged Windows and Linux zoom check.
