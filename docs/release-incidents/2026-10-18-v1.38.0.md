# Blanc v1.38.0 release — October 18, 2026

Status: published and independently verified; public v1.38.0 is the baseline.
It went through on the first attempt. The owner confirmed the adjacent
v1.37.0 → v1.38.0 updater handoffs on macOS and Windows on October 18. The
Windows and Linux hand checks of the two new Start Page wallpapers are
pending.

## Scope

A minor release with these app changes merged since v1.37.0.

- **Your own Start Page image (F49, #945).** Customize → Wallpaper offers
  Sunrise | Your image; Settings → General → Start Page image offers the same
  choice. Under Your image: Choose another image… / Remove, Wash (Auto,
  Light, Dark, Spotlight) and Fade (0–100%). The image is a JPEG or PNG up to
  25 MB, fitted inside 3840 px and re-encoded with only the orientation tag
  kept, stored owner-only at `userData/wallpaper/current.jpg`. The page
  reaches it at a random per-launch name. `newtabCustomWallpaper`,
  `newtabWallpaperWash` and `newtabWallpaperStyle` are device-local and never
  synced, and private tabs never get the image or the controls.
- **Start Page Color (F50, #952).** Wallpaper becomes Sunrise | Color | Your
  image. Color takes one of the eight Spaces presets, a Soft, Solid or
  Gradient fill, and a Match each space's color switch that paints a window
  belonging to a space in that space's color (the page receives only the hex
  value). `newtabColorWallpaper`, `newtabWallpaperColor`,
  `newtabWallpaperFill` and `newtabFollowSpaceColor` are synced; this
  device's own image still takes priority here; private tabs never show a
  color. The colors come from the Electron-free `src/main/start-page-paint.js`,
  which keeps ink and dim ink at 4.5:1 or better.

Release notes: [v1.38.0](../press/release-notes/v1.38.0.md) (prep #955).

## The release run

Launched in Terminal.app at 19:06 UTC from `87538dee`. Every gate passed on
the first try:

- **Press gate:** 3,813 unit tests, and 390 desktop scenarios with 2,558
  steps.
- **Builds:** the macOS identity and profile preflight, then both notarized
  builds.
- **Packaged checks:** fuses, byte-identical blocker payloads, compliance
  payloads, first run, release regressions, Workspace quit/restart, both live
  favicon matrices, and migration from public v1.37.0.
- **Native build:** the tag and draft were created, then native run
  `39158977061` (19:29–19:35 UTC) built and signed Windows and Linux.
