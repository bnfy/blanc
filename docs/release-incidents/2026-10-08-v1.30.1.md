# Blanc v1.30.1 release — October 8, 2026

Status: published and independently verified; public v1.30.1 is the baseline.
The adjacent public-feed updater handoffs (v1.30.0 → v1.30.1) on macOS and on
the Windows VM's normal install are pending owner confirmation.

Scope: a patch release with two app changes merged since v1.30.0.

- The Island's growth as the pointer approaches it now eases once per display
  frame in the chrome renderer instead of restarting a 220 ms CSS transition
  on every proximity update (#627). Measured with a synthetic-cursor frame
  probe on macOS and in the Windows 11 VM, both at 120 Hz: stop-start frames
  fell from 19–20% to 0–2% and the largest single step from about 3.2× to
  1.4–1.5× a typical step. Native Windows hardware and displays above 120 Hz
  were not measured. Under reduced motion, `--island-k` is now painted as 0
  so the reported Island rect matches the untransformed pill.
- Patron license handling (#419): activation reports Polar 429/5xx as
  "Polar is not responding right now" instead of "could not be activated",
  and a validation answered by Polar's 404 `ResourceNotFound` (missing,
  revoked or expired key) now ends Patron instead of being treated as an
  outage. Other failures keep the existing 30-day grace.

The other changes merged since v1.30.0 are website, Worker, documentation and
test-only. Release notes: [v1.30.1](../press/release-notes/v1.30.1.md).
Stable mode, platforms `mac,windows,linux`, `BLANC_MAC_ARCHES=arm64,x64`, from
`9e337ac583e81bae509cfc970b9d97a81f3287ba` (PR #631).
