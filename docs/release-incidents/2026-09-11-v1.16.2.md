## Scope

- Chrome Web Store main-frame requests are intercepted before the affected
  Electron path can trigger its native crash. Blanc shows a local explanation
  page while the upstream correction remains unavailable.
- Restored Chrome Web Store tabs recover through the same guard without
  preventing the rest of the saved session from opening.
- The macOS About panel now uses the monotonic bundle build number `1162`, so it
  displays `Version 1.16.2 (1162)` instead of repeating the public version.
- Migration verification used the immediately preceding public v1.16.1 build.

## Known limitation

Chrome Web Store pages are temporarily unavailable inside Blanc. Electron's
44.x backport <https://github.com/electron/electron/pull/53776> remained open
during preparation and Electron 44.3.0 did not contain the correction. The
guard keeps Blanc running and explains the limitation locally; users can browse
the store in another browser until Blanc adopts the upstream fix.
