# Blanc v1.51.0 release — November 18, 2026

Status: published and independently verified at 22:47 UTC on November 18,
2026 (17:47 EST), from `2c3d17db9b8573f4047e8732aaf8f0972ef9e724`. The first
`release.sh` attempt stopped at its first step when the 1Password
authorization timed out before the owner approved it (nothing was built,
tagged or published); the second ran end to end and exited 0. The press gate
ran on the owner's Mac Studio; two acceptance scenarios that the Studio's
environment fails (as it did for v1.50.0 and the published v1.49.1) passed on
the release Mac with the owner's approval. The macOS and Windows updater
handoffs from v1.50.0 are pending.

## Scope

The 1.51 feature release, on the same runtime as v1.50.0, castLabs' Electron
for Content Security `45.2.1+wvcus`. Checked on November 18, 2026, before
signing, castLabs' newest stable release was still `v45.2.1+wvcus`; the only
newer one was the `v46.0.0-alpha.7+wvcus` pre-release.

Release notes: [v1.51.0](../press/release-notes/v1.51.0.md), prepared in #1626
(merged as `b50997ca6`).

- **Added:** Favorites as a full page in a tab, with **Edit…** for a
  favorite's name, address and folder (#1614); widgets on the one Start Page
  (#1618).
- **Changed:** the Start Page's wallpaper continues behind the Island's top
  band, the launch Sunrise included (#1622, #1624); Customize makes room by
  shrinking a tall clock (#1625).

Not hand-checked before release (listed in `unreleased.md`): the Start Page
cards with a real mouse and finger and over a real photo in packaged builds,
the band on Windows and Linux, Customize at the smallest windows, and the
Favorites page in packaged builds.

## Press gate

Run with `npm run release:prepare` on the Mac Studio in a detached worktree at
`2c3d17db9`, with the release Mac's Node 22.23.4 and npm 11.4.2 and its
`BLANC_1P_ACCOUNT` passed over stdin. Both machines computed the same gate key
before the run, and the Studio's ledger was copied into the release worktree.

The Studio run passed every stage except 2 of 627 acceptance scenarios, which
failed on the first run and again on the fresh rerun, as they did on the
Studio for v1.50.0: `quiet-tabs.feature:77` (the panel row's opacity stayed 1)
and `tabs-and-groups.feature:367` (the pill measured 1px taller than expected
at every size). The third Studio-only failure from v1.50.0
(`island-and-commands.feature:87`) passed this time. The owner approved
running the two on the release Mac (MacBook Pro, Retina), where
`release:prepare` passed them.
