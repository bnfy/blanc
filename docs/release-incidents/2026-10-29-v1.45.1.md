# Blanc v1.45.1 release — October 29, 2026

Status: published and independently verified at 22:38 UTC on October 29, 2026,
from `85883b1afa11375e1300130914d6f40c5388af21` (prep PR #1267), on the first
attempt. The owner confirmed the macOS and Windows updater handoffs from
v1.45.0 on October 29, 2026.

## Scope

A bug-fix release on the same castLabs Electron for Content Security pin as
v1.45.0 (`44.9.3+wvcus`, Chromium 152.0.7977.167), so Widevine playback, uBO's
reviewed runtime record and the owner's runtime waivers in
[the ECS runtime security review](../ecs-runtime-security-review-2026-10-23.md)
carry over unchanged. On October 29, 2026 `44.9.3+wvcus` was still castLabs'
newest 44.x stable release (`gh release list -R castlabs/electron-releases`:
the newer tags are 42.11.18 and 43.8.3). Release notes:
[v1.45.1](../press/release-notes/v1.45.1.md).

- **Changed:** a shared Space's sync status sits on its own line under its
  name in the Spaces menu (#1266).
- **Fixed:** "Sync is busy; retrying." and "Waiting to upload" no longer show
  for routine Shared Spaces sync (#1264); a link opened in the background whose
  rule needs a new window opens that window behind the current one (#1263).

Also on main at the release commit, with no desktop app code: iOS M17c (#1247),
the iPhone app icons (#1268) and a TestFlight record (#1269). A bug-fix
release needs no What's New page; `release.sh` skipped that check.

The owner approved the release notes text on October 29, 2026 before #1267
merged.

## The release run

`npm run release` ran in a native Terminal.app window from a clean worktree
detached at `origin/main`, under `caffeinate -dimsu`, with
`BLANC_RELEASE_RUNTIME=ecs`, `BLANC_RELEASE_PLATFORMS=mac,windows,linux` and
`BLANC_MAC_ARCHES=arm64,x64`. The log's first line reads
`mode=stable, runtime=ecs, platforms=mac,windows,linux, mac=arm64,x64`.

- Started 21:10 UTC. 1Password sign-in through the script's own
  `op signin`.
- Press gate: 5,098 unit tests passed (2 skipped, 0 failed). The desktop
  acceptance gate passed all 580 scenarios and 5,110 steps on its first run
  (21:15–21:39 UTC), so it printed no `Acceptance rerun passed` block. The
  production audit found 0 vulnerabilities.
- Both Mac architectures were VMP-signed, Developer ID signed and notarized,
  then passed every packaged check, including ECS acceptance (installed uBO,
  file isolation, protected playback with `mediaKeys: true` and a sandboxed
  CDM process).
- The tag `v1.45.1` was pushed at about 22:01 UTC and the draft created with
  the full macOS asset set. Uploading the 733 MB set took about 14 minutes.
- Native release run
  [`40964375955`](https://github.com/bnfy/blanc/actions/runs/40964375955)
  passed on its first attempt: Linux in 9 minutes (with the Ubuntu 22.04
  legacy launch), Windows in 7. The Windows job waited 15 minutes (22:15–22:30
  UTC) at the `ecs-signing` environment's reviewer gate before Claude approved
  it under the owner's standing release approval of October 24, 2026.
- The Sigstore loopback page completed in Safari at 22:38 UTC, then the
  verified draft was published, the logged-out download smoke passed, and
  `release.sh` exited 0.

## The acceptance gate's pauses

The gate's 580 scenarios took 24.1 minutes of test time, 14.0 of them in
Shared Spaces. Six `@F57` scenarios had steps that each waited about 60
seconds for the sync request window (10 reads per minute). The four added for
1.45.0 (`@F57-15` to `@F57-18`) did so only because their checks lacked the
test-only window reset that #1187 gave the older steps. #1272 adds it there
(7 min 12 s for those four down to 12 s; all 26 `@F57` scenarios in 8.9
minutes). The nightly macOS acceptance job had been growing toward its
30-minute limit for the same reason and was cancelled at it on October 29
(run 40842342958).
