# Blanc v1.42.0 release — October 22, 2026

Status: published and independently verified; public v1.42.0 is the baseline.
It published on the third attempt. The first two stopped in the press gate,
before any tag or draft existed, on timing-sensitive Island auto-hide
scenarios while the Mac was in Low Power Mode. With the owner's approval no
What's New page was made: 1.42 is in `noPage` (#1047). The owner confirmed
the macOS and Windows updater handoffs from v1.41.0 and Search priority
results on Mac and Windows, and waived its Linux check.

## Scope

A minor release with these app changes merged since v1.41.0.

- **Search priority results (#1042).** Settings → General → Island gains an
  opt-in, device-local setting, off by default. When on, the exact search row
  and the engine's suggestions lead typed results and take Enter, above open
  tabs, groups, Spaces, Favorites and history. Never synced; main sends the
  value with every `overlay:show`.
- **Fix:** on Windows and Linux the first permission prompt in a window no
  longer keeps the keyboard; the hand-back is deferred with `setImmediate` so
  Chromium's own focus move doesn't override it (#1040, checked with real
  keystrokes in the Windows and Linux VMs before merge, #1038).
- **Fix:** the floating Island casts one shadow, from its surface, instead of
  two stacked shadows that drew a second outline along its bottom edge
  (#1043).

Release notes: [v1.42.0](../press/release-notes/v1.42.0.md) (prep #1046).
Stable mode, platforms `mac,windows,linux`, `BLANC_MAC_ARCHES=arm64,x64`, from
`f251a862c12a282a67bdbef85705a88e54631c2a`. Electron stays 44.8.0 (Chromium
152.0.7977.167), so `src/main/ublock-platforms.json` is unchanged. Between the
prep merge and the release commit, only #1047 (the `noPage` entry) and #1048
(measurement choices beside the website's downloads) landed, both website
only.

## The release runs

**Attempts 1 and 2** ran from `2a47e4fc` and stopped in the press gate's
desktop acceptance run, before the build, tag or draft:

- Attempt 1: 463 of 472 scenarios passed. The 9 failures were eight Island
  auto-hide reveals (push and float: `island-and-commands.feature` lines 200,
  222, 241, 258, 276, 320, 339, 372) and "Move a loose tab into a group"
  (`tab-drag.feature:46`), each after its two attempts. All nine passed when
  rerun alone on the same commit.
- Attempt 2: 470 of 472 passed. The two failures were also auto-hide reveals
  (lines 140 and 180), each timing out waiting for the strip to be shown.

These steps fake the cursor sample, so the real pointer couldn't cause them,
and the display didn't sleep during either run. The Mac was in Low Power Mode
at 9–14% battery. The owner turned Low Power Mode off and, as no tag existed,
the same version was rerun.

**Attempt 3** ran from `f251a862` (main had gained website-only #1048), and
every gate passed:

- **Press gate:** 4,213 unit tests, and 472 desktop scenarios with 3,154
  steps.
- **Builds:** the macOS identity and profile preflight, then both notarized
  builds.
- **Packaged checks:** fuses, byte-identical blocker payloads, compliance
  payloads, first run, release regressions, Workspace quit/restart, both live
  favicon matrices, and migration from public v1.41.0.
- **Native build:** the tag and draft were created, then native run
  `39796047190` (14:29–14:44 UTC, queued behind GitHub's degraded Actions
  performance) built and signed Windows and Linux.

The Sigstore loopback page in Safari completed on the first try. The bundle
verified, the draft was published at 14:46:10 UTC on October 22, the
logged-out download smoke passed, `site/src/data/releases.json` was
refreshed, and the script exited 0.
