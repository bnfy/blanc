## Pending release gates

Affected physical Windows/Linux checks have not been performed for the new
Help/tint and security changes. In particular, Ubuntu 22.04/24.04 real desktop
sandbox launch/visibility, packaged Help/tint appearance, close-last-window
exit and relaunch, and the signed Windows staged Restart Now handoff beginning
in public v1.25.0 remain unverified. Hosted checks cannot establish those
physical-machine outcomes. Linux sandbox enforcement can refuse browsing on
restricted systems; a Windows handoff defect can prevent installation or
relaunch; compositor differences can affect Island tint or window behavior.

Source-merge authorization in PR #477 and earlier audit PRs does not certify
these checks or waive release gates. Obtain explicit affected-machine
confirmation or an explicit release waiver after describing the missing
evidence and risks. Signed builds, publication and immutable tagging remain
pending. Post-publication independent checks and adjacent public updater
handoffs must be recorded separately from installation tests.
