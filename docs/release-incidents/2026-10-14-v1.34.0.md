# Blanc v1.34.0 release — October 14, 2026

Status: published and independently verified; public v1.34.0 is the baseline.
The owner confirmed both adjacent public-feed updater handoffs (v1.33.0 →
v1.34.0), on macOS and on Windows, and the website is deployed.

## Scope

A minor release with these app changes merged since v1.33.0.

- **Kagi and a custom search address (#815).** Prompted by a Reddit user who
  couldn't use Kagi or SearXNG. Settings → General → Search engine adds Kagi
  and **Custom…**: the user's own search address with exactly one `%s` after
  the host and port. The address is `https://` anywhere, or `http://` only for a
  local-network host. It syncs with the engine choice, and a refused address
  keeps the previous engine.
  - Kagi has live suggestions from its documented, cookie-free suggestion
    address; custom engines get none.
  - Every search path uses one resolver, `currentSearchEngine()`.
  - **Also fixed in #815:** engine ids such as `constructor` were accepted;
    Paste and Go turned `site:example.com` into a broken address; field
    errors in Settings drew in grey; and an invalid Encrypted DNS custom
    address could switch DNS to an older stored one. The custom-address
    fields gained accessible names and announced errors.
  - **Spec and plan:**
    `docs/superpowers/specs/2026-10-14-kagi-and-custom-search-design.md` and
    `docs/superpowers/plans/2026-10-14-kagi-and-custom-search.md`.
- **Settings site exception lists (#796).** They sit under their switches in
  one bordered box, and each site has an always-visible ×.
- **Linux tab drawing (#798).** Pages shown again after switching tabs,
  Glance, reopening, returning to a space or moving windows, and quieted tabs
  that keep session data, now keep drawing. #810 added the packaged AppImage
  check for it.
- **Window close on Windows and Linux:**
  - **#814:** closing the last window with Blanc's own ✕ keeps its tabs for
    the next launch.
  - **#817:** a closed original window stays closed, its pages stop running,
    and no extra empty window appears after restoring only a second window.
- **#816** changes no app behaviour: it adds a test and a code note for
  Electron's Windows guard on several command-line URLs (`Blanc.exe -- URL1
  URL2`).
- **1Password fill** on Windows and Linux stays enabled and **unannounced**,
  under the waiver in [the 1Password integration doc](../1password-integration.md).

Release notes: [v1.34.0](../press/release-notes/v1.34.0.md). Stable mode,
platforms `mac,windows,linux`, `BLANC_MAC_ARCHES=arm64,x64`, from
`ac16aae446c22732478bfebc45ecc7ce5de51fbd` (PR #820). Electron stays at
44.5.1.

## Why 1.34.0, not 1.33.1

#809 prepared 1.33.1 (the Settings lists and the Linux fix). It was never
tagged, drafted or published. After #815 merged, the owner chose to ship
everything together as a feature release, and to pull #814, #816 and #817
into it. They had been held for "after v1.33.1 is tagged".
- #818 re-prepared `main` as 1.34.0. The v1.33.1 notes moved into
  `v1.34.0.md` unchanged.
- #819 added the window-close lines.

in #818. Both public Mac apps report 1.34.0 (1340).

installer directly does not count.

to v1.34.0 inside Blanc, clicking **Restart Now**.

- **Updater log:** at `01:21:29Z` public v1.33.0 found 1.34.0. It downloaded
  `Blanc-1.34.0-arm64-mac.zip` by `01:21:33Z`, and Squirrel.Mac staged it at
