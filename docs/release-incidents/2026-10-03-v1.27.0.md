# Blanc v1.27.0 release — October 3, 2026

Status: owner approved; publication and final artifact verification pending.
The current public baseline remains v1.26.0 until the release completes.

Scope: optional full uBlock Origin 1.75.0 on official Electron 44.5.1 for
macOS arm64, native macOS x64, Windows x64, and Linux x64. Blanc Blocker stays
the default and protects private tabs. Intel under Rosetta is excluded after
two retained startup failures. Version 1.27.0 uses macOS bundle build 1274.

`BLANC_MAC_ARCHES=arm64,x64`, platform scope `mac,windows,linux`, stable mode.
