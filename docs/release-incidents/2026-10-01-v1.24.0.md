# v1.24.0 time-of-day wallpaper and Linux AppImage release — 2026-10-01

Status: [v1.24.0 is public](https://github.com/bnfy/blanc/releases/tag/v1.24.0) and independently verified. Canonical website deployment and adjacent public Mac/Windows updater handoffs are pending. The recorded physical Windows/Linux and Michael-machine waivers remain waivers, not passes.

Release preparation: [PR #456](https://github.com/bnfy/blanc/pull/456), squash-merged as `467b6f62e0c48105ee7b437ce38d0d218e099f30`.

## Scope

- Ship the free, optional local-clock Sunrise wallpaper and its start-page footer switch from PRs #453 and #455, including two-second fades and reduced-motion handling.
- Ship PR #443's AppImage runtime without the FUSE 2 dependency and corrected packaged desktop arguments. Keep the existing sandbox fallback on hosts that block the capability probe.
- Include the merged dependency advisory fixes. Flatpak compatibility remains in its separate draft PR and is outside this release.
- Advance the app to 1.24.0, macOS bundle build number to 1240, and official, unmodified Electron to 44.5.1. Electron's official release notes record upstream ANGLE, Chromium, Dawn, and V8 fixes: <https://github.com/electron/electron/releases/tag/v44.5.1>.

## Release authorization and physical Windows/Linux waiver

The owner requested “cut new release” on October 1. That authorizes preparation and the ordinary release workflow. The merge-only acceptance exceptions in [the wallpaper record](2026-10-01-time-of-day-wallpaper-merge.md) do not independently waive physical Windows/Linux release checks.

Installed Windows/Linux wallpaper appearance, fades, activation, resume, hidden-tab timers, close-last-window exit, and normal relaunch remain unconfirmed on affected machines. Hosted signed/package checks and Linux smoke tests cannot fully rule out native desktop appearance, compositing, or lifecycle defects. After PR #456, both private package candidates, the local press gate, and the refreshed Linux updater rehearsal were presented with this missing evidence and risk, the owner explicitly replied **“yes I waive them”** on October 1, 2026 to the request to waive physical Windows/Linux checks for v1.24.0. This waives those physical pre-release package checks only; it does not mark them passed or waive automated release verification. The release is authorized to proceed through the normal protected merge and signed release workflow. Adjacent public macOS and Windows updater handoffs remain post-publication checks.

## Existing Linux confirmation waiver

The owner already waived confirmation of the AppImage fix on Michael Staengl's machine and chose to ship it in the next public release. That authorization persists; this is a waiver, not a pass. The original failure was reproduced by removing FUSE 2 from public v1.23.0, and the fixed staging builds launched without it and completed two in-app Restart Now handoffs in hosted rehearsal run <https://github.com/bnfy/blanc/actions/runs/36888774946>. See [the Linux investigation](../linux-appimage-sandbox-2026-09-29.md) for the limits, desktop launcher and renderer isolation observations, and the owner's recorded exception.

This existing waiver covers Michael's machine confirmation only. It does not convert the new wallpaper's physical desktop acceptance into a pass or waive normal automated release gates.
