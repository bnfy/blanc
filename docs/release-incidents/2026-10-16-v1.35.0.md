# Blanc v1.35.0 release — October 16, 2026

Status: published and independently verified; public v1.35.0 is the baseline.
Both adjacent public-feed updater handoffs (v1.34.0 → v1.35.0) are pending the
owner's confirmation; the macOS updater log already shows one (below). The
website is not deployed: blanc.day deploys are on hold for the homepage
redesign, and the owner decides when this release's changelog goes live.

## Scope

A minor release with these app changes merged since v1.34.0.

- **Custom tab names (F46, #824).** Rename Tab… in the tab right-click menu
  and `/rename`; Reset Tab Title and `/rename` alone go back to the page
  title. The name stays through navigation, Quiet Tabs, Move Tab to New
  Window, Reopen Closed Tab, Blanc Spaces and relaunch, and travels with Tab
  Sync. History and Favorites keep page titles; a private tab's name is memory
  only. **Also fixed in #824:** shortened `/gr`, `/sav`, `/spa` and `/the`
  leaked the command into their argument.
- **Glance, three PRs** from
  `docs/superpowers/specs/2026-10-15-glance-refinement-design.md`:
  - **#842 (fixes):** audible media in the reference, promotion when the main
    page moves or its group closes, focus return, the picker's cancel race,
    the divider grab offset, the stacked Island and picker, readable Windows
    and Linux window controls over the header, the one-tab picker, spoken
    reorder announcements, and screen sharing from the reference. Its Windows
    VM hand check is recorded by #851.
  - **#844 (the reference behaves like a page):** commands follow the focused
    pane, new tabs from the reference open into Glance, header Back and
    Reload/Stop, Back/Forward shortcuts (⌘[ and ⌘] on macOS, Alt+Left/Right on
    Windows and Linux), and the Island's clearance of the window controls.
  - **#849 (polish):** motion, picker rows, the private chip, `/glance`, and
    Open Link in Glance.
- **PDF viewer (#848).** Every PDF had opened as an empty viewer since v1.20.0;
  Chromium's built-in viewer may now load its own document frame.
- **Chrome account bookmarks (#835).** Favorites import also reads a signed-in
  Chromium profile's `AccountBookmarks` file.
- **uBO filter-list reload (#838).** Request decisions wait while uBO reloads
  its filter lists instead of being allowed.
- **Idle memory (#831).** The screen-sharing helper starts on the first share
  request instead of at launch; macOS 26+ no longer re-applies the bundle's own
  Dock icon at launch; the blocker snapshot check no longer builds the list
  text.
- **Interface type and palette (#840):** Instrument Sans for UI text and the
  Blanc White light palette. **Vector Sunrise mark (#841)** for every app icon
  and in-app mark.
- **1Password fill** on Windows and Linux stays enabled and **unannounced**,
  under the waiver in [the 1Password integration doc](../1password-integration.md).

Release notes: [v1.35.0](../press/release-notes/v1.35.0.md). Stable mode,
platforms `mac,windows,linux`, `BLANC_MAC_ARCHES=arm64,x64`, from
`95e1c2c1adb26bc223dfd8a4f98246984d43bd89` (PR #852). Site-only, docs-only and
test-only commits since v1.34.0 (#821–#823, #825, #826, #829, #830,
#832–#834, #836, #843, #845, #846, #850, #851) change no app behavior.

## Electron 44.8.0

The owner asked for the Electron update in this release ("we need to bump
Electron now"). #852 moved the `electron` devDependency from 44.5.1 to
**44.8.0** (Chromium 152.0.7977.130 → 152.0.7977.167). 44.6–44.8 carry
Electron's backports of upstream Chromium, V8, ANGLE, Skia, PDFium and WebRTC
fixes. The lockfile change is the Electron package only.

- **uBlock Origin runtime record.** `src/main/ublock-platforms.json` makes uBO
  available only on the exact reviewed Electron version, so it moved to
  `44.8.0` with the dependency. Without it every uBO user would have been
  switched back to Blanc Blocker with a notice.
  [`docs/ublock-origin-shipping-2026-10-03.md`](../ublock-origin-shipping-2026-10-03.md)
  requires any Electron update to "pass the real blocking/tools suite on every
  enabled platform before release": the four `desktop (…)` jobs of
  [run 38940435065](https://github.com/bnfy/blanc/actions/runs/38940435065)
  passed on #852's head `0646b46b` on macOS Apple Silicon (`macos-15`), native
  Intel (`macos-15-intel`), Windows x64 and Linux x64. uBO 1.75.0 and its
  pinned upstream files are unchanged.
- **Linux view re-attach.** Electron 44.7.1 changes the Linux behavior that
  `src/main/tab-view-lifecycle.js` works around (#798). CI's
  `test:tab-view-drawing:desktop` passed under Xvfb and on Windows, the
  private validation run's packaged AppImage check passed, and the Ubuntu VM
  check below passed on native Wayland.
- **macOS updater.** Electron 44.7.0 rewrote how macOS downloads and installs
  updates. 1.34.0 → 1.35.0 still runs inside 1.34.0's Electron 44.5.1; the
  first update on the new code is 1.35.0 → the next release. At the owner's
  choice it was rehearsed before release (below).
