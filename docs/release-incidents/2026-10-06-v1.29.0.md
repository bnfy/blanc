# Blanc v1.29.0 release — October 6, 2026

Status: published and independently verified; public v1.29.0 is the baseline.
The adjacent public-feed updater handoffs (v1.28.0 → v1.29.0) on macOS and
Windows are pending.

Scope: About & Trust in Settings (#589), Intel Mac builds in every release
(#598), background JSON-store saves (#606), automatic uBO restart after a
mid-session failure (#596), the uBO decision-deadline grace for Blanc's own
main-process freezes (#599), the Dock icon reload fix (#592), the Flatpak
update channel (#582), and the Linux Wayland utility-sheet (#595) and
permission-prompt (#600) fixes. Release notes:
[v1.29.0](../press/release-notes/v1.29.0.md). Stable mode, platforms
`mac,windows,linux`, `BLANC_MAC_ARCHES=arm64,x64`, from
`f4b61281d990e492b88257cca3c034f56d5e7fe1` (PR #607).

## macOS build number

`build.mac.bundleVersion` moved from 1274 to **1290** in the release-prep PR,
resolving the duplicate build recorded in the
[v1.28.0 report](2026-10-05-v1.28.0.md). Both public Mac apps report
1.29.0 (1290).

## Pre-release checks

- PR #607's checks passed on its head SHA. One unit test,
  `turning share-tabs off before restore still publishes retractions`, failed
  on `windows-latest` in [run 37552316440](https://github.com/bnfy/blanc/actions/runs/37552316440)
  and passed on rerun. It slept a fixed 300 ms for a store save that #606 now
  writes off the main thread; the test-only fix is PR #608.
- `npm audit --omit=dev --audit-level=high` reported 0 vulnerabilities.
- No separate installed-candidate uBO acceptance was run for #596 and #599;
  their coverage is the hosted four-platform uBO desktop suite on PR #607 and
  the press gate below. Hosted runs are not physical-machine confirmation.
