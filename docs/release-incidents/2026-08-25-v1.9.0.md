# v1.9.0 release verification — 2026-08-25

Blanc v1.9.0 was published from source commit `e55fc13` after the complete
stable release gate passed for macOS arm64, Windows, and Linux.

- GitHub release: <https://github.com/bnfy/blanc/releases/tag/v1.9.0>
- Native build workflow: <https://github.com/bnfy/blanc/actions/runs/32807638307>
- Published at: `2026-08-25T04:09:19Z`

## Scope

The release includes the explicit, opt-in macOS 1Password login-fill action,
the revised Blanc icon family, restored quiet-tab representation in the
Island's tab dots, and Electron 44. The unfinished "Bring your tabs" migration
feature is not present in the release source.

## Publication evidence

- The clean release checkout passed all 1,062 unit tests, 118 live desktop
  acceptance scenarios / 719 steps, cold launch, OAuth, DNS, production
  dependency audit, generated-source checks, Windows icon checks, and site
  build.
- The macOS app passed Developer ID signing, Apple notarization, strict
  designated-requirement validation, provisioning-profile/WebAuthn checks,
  hardened Electron fuses, byte-identical packaged blocker verification,
  packaged first-run and regression smokes, both live favicon matrices (51
  sites total), and the v1.8.2 migration smoke.
- The Windows job built and uploaded the installer only after artifact,
  packaged blocker, hardened-fuse, and exact publisher/timestamp Authenticode
  verification. `windows-signature.json` binds the observation to the
  installer digest.
- The Linux job built and uploaded the AppImage only after artifact, packaged
  blocker, and hardened-fuse verification.
- GitHub provenance attestations completed for the native Windows and Linux
  artifacts.
- The complete 13-artifact release manifest was checksummed, signed with the
  pinned Sigstore GitHub identity, verified locally, uploaded, published, and
  passed the logged-out download smoke.

## Follow-up evidence

Publication does not itself prove an updater restart handoff. The real public
v1.8.2 → v1.9.0 **Restart Now** flows on macOS and Windows remain to be run and
recorded, and the downloaded public v1.9.0 AppImage still needs a launch/render
confirmation. Until those checks are added here, do not claim them from a
direct installer launch, the local migration smoke, or the CI build alone.
