## Release scope and What’s New

1.53 adds moving a mini window to a Space and opening local HTML in a static
preview from Linux file managers. It also fixes menu shortcuts and improves
screen reader labels. [Release preparation PR #1781](https://github.com/bnfy/blanc/pull/1781)

The owner approved the What’s New page and its captures from the candidate.
The page and both capture URLs returned HTTP 200 before signing. Cloudflare
reported Production deployment `6dfb75cd-bcc6-461c-8a67-0f56d9a6e886` for
`main` at `c060b5f`. [What’s New](https://blanc.day/whats-new/1.53) ·
[Site PR #1782](https://github.com/bnfy/blanc/pull/1782)
