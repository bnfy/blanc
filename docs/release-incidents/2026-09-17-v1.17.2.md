## Scope

- Blanc exits cleanly after the last visible window is closed on Windows and
  Linux (issue #368). Since v1.16.0 the display-capture broker's hidden helper
  `BrowserWindow` outlived the visible window, Electron withheld
  `window-all-closed`, Blanc stayed alive in Task Manager, and a relaunch
  deferred to the stuck instance through the single-instance lock. macOS
  behavior is unchanged; the helper survives there for Dock reopen.
- Electron stays at 44.4.1. The macOS bundle build number advanced from 1171
  to 1172.
