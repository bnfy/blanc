# Blanc v1.43.0 release — October 24, 2026

Status: published and independently verified, then superseded the same day by
v1.43.1. It published on the third attempt. Its Linux AppImage didn't start on
glibc older than 2.38, so its Linux updates were contained and the fix shipped
as [v1.43.1](2026-10-24-v1.43.1.md). The macOS and Windows updater handoffs
from v1.42.1 are pending owner confirmation.

## Scope

The first release on castLabs' Electron for Content Security (ECS) 44.9.3
(`44.9.3+wvcus`, Chromium 152.0.7977.167, the same Chromium as official
Electron 44.8.0 in v1.42.1), merged through #1063.

- **Added:** Widevine protected video playback on macOS (Apple Silicon and
  Intel), Windows and Linux; Sunrise Spectrum and Sunrise Amber macOS app
  icons; the Neutral surface style.
- **Changed:** pinned splits; the ECS runtime; static previews for HTML files
  opened from Finder and inert records for restored local HTML tabs; tabs a
  page opened keep its restrictions (#1078).
- **Fixed:** the startup-gate "blocked" error page over a page that loaded.

Release notes: [v1.43.0](../press/release-notes/v1.43.0.md). The 1.43 What's
New page, the privacy and Trust Widevine wording and the final notes were
signed off by the owner and deployed before the release (#1082, Cloudflare
deployment `6fed0e2b`). Stable mode, platforms `mac,windows,linux`,
`BLANC_MAC_ARCHES=arm64,x64`, `BLANC_RELEASE_RUNTIME=ecs`.

## Waivers

The owner waived two runtime gates in writing on October 23, 2026 at 22:06
UTC, recorded in [the ECS runtime security review](../ecs-runtime-security-review-2026-10-23.md):
the Node 24.22.0 TLS defects (fixed in Node 24.22.1, which no Electron 44.x
tag or castLabs release carried yet) and the native source review. They are
waived, not passed, and cover this runtime pin only.

## Linux AppImage didn't start on glibc older than 2.38

Hosted `prerelease-smoke.yml` run `40096106402` passed four of five jobs. The
`published-linux-appimage` job on Ubuntu 22.04 (glibc 2.35) failed: the
AppImage exited before Blanc started. Its DRM launcher `blanc-ecs-launcher`
needed `GLIBC_2.38` and `GLIBCXX_3.4.32`, and the CDM preload
`blanc-cdm-preload.so` needed `GLIBC_2.34`, because both were compiled with
the Ubuntu 24.04 release runner's toolchain; the castLabs runtime itself needs
only glibc 2.25. Every Linux validation had run on Ubuntu 24.04. Ubuntu 22.04
LTS, Debian 12 and other distributions with glibc below 2.38 were affected.

**Containment (owner-approved):**

- At 13:03 UTC the `latest-linux.yml` asset (365 bytes, SHA-256
  `8af9b1198e9f9e77f9d9f9215abdeb86fc6064f8732db56e936eca6a0e1df4c4`, 0
  downloads) was removed from the published release, so Linux 1.42.1
  installs found no update. `SHA256SUMS` and its Sigstore bundle still list
  it, so a full-manifest check of v1.43.0 reports it missing; that is this
  containment, not tampering.
- #1085 pinned `blanc.day/dl/linux` (and the `blancbrowser.com` redirect) to
  the 1.42.1 AppImage; the ping Worker was deployed as version
  `1c39ea9e-3090-41b5-bd5a-f7aa5ab9ed6e`.
- `Blanc-1.43.0.AppImage` had 13 downloads by the time v1.43.1 published.
  Those copies can't start to update themselves; v1.43.1's notes ask their
  owners to download again.

**Fix:** #1086 links the launcher statically and builds the preload in a
pinned `manylinux_2_28` image, checks both against a glibc 2.28 baseline in
packaging, and adds a release-workflow job that launches the built AppImage on
Ubuntu 22.04 before upload. It shipped as v1.43.1.
