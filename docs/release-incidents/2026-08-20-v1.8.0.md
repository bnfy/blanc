## macOS v1.7.0 to v1.8.0 updater handoff

The normal public updater path completed from the signed v1.7.0 app installed
at `/Applications/Blanc.app`:

1. At `2026-08-21T02:54:32Z`, Blanc's persisted updater log recorded the live
   feed result `Found version 1.8.0` and selected
   `Blanc-1.8.0-arm64-mac.zip`.
2. The full 133.4 MB release ZIP downloaded, reached 100%, and passed the
   feed-provided SHA-512 check.
3. At `2026-08-21T02:54:37Z`, electron-updater recorded native
   `update-downloaded` and handed the verified ZIP to Squirrel.Mac.
4. ShipIt recorded an install request, replaced `/Applications/Blanc.app`,
   reported `Installation completed successfully`, and successfully relaunched
   the application.
5. The relaunched app recorded a feed check as v1.8.0, and its installed
   `CFBundleShortVersionString` was independently read back as `1.8.0`.

This is updater-handoff evidence: the old packaged app discovered and
downloaded the public release, and Squirrel.Mac installed and relaunched it. It
is not a direct DMG or ZIP launch.
