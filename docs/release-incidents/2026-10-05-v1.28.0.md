# Blanc v1.28.0 release — October 5, 2026

Status: published and independently verified; public v1.28.0 is the baseline.
Adjacent public-feed updater handoffs (v1.27.0 → v1.28.0 on macOS and Windows)
remain pending until the owner confirms each through **Restart Now**.

Scope: Dark websites, Match site colors, resumable and retryable downloads,
continuing past certificate warnings on local addresses, the start-page layout
polish, three uBlock Origin host fixes (#534, #567, #568), the utility-sheet
load deadline and the Island footer overflow fix. Release notes:
[v1.28.0](../press/release-notes/v1.28.0.md). Stable mode, platforms
`mac,windows,linux`, `BLANC_MAC_ARCHES=arm64`, from `ec98a138` (PR #574).

## Duplicate macOS build number

Version 1.28.0 shipped with macOS bundle build **1274**, the same build as
v1.27.0. The release-prep PR bumped `version` but not
`build.mac.bundleVersion`, and no gate compares the build with the previous
public release. Updates are unaffected: Squirrel.Mac and electron-updater
compare the version string, and the staged 1.27.0 → 1.28.0 update below
passed. The visible effect is that About reads "1.28.0 (1274)". Released
assets are immutable, so the next release must move `bundleVersion` above
1274.

#567 and #568: **“hosted runs plus Apple Silicon is enough.”** The uBO
executable payload (1.75.0, 658 pinned files) is unchanged from v1.27.0.

- CodeQL on main: no open alerts; the 39 dismissed alerts are all vendored
  `ublock/upstream`.
- PR #574's checks, including the four-platform uBO desktop suite, passed.
- [Signed Windows/Linux validation run 37394227593](https://github.com/bnfy/blanc/actions/runs/37394227593)
  and the [unsigned installed Intel uBO run 37394229839](https://github.com/bnfy/blanc/actions/runs/37394229839)
  passed.
- [Linux update rehearsal 37394188545](https://github.com/bnfy/blanc/actions/runs/37394188545)
  passed from public v1.27.0 to the candidate.
- Apple Silicon, on a locally signed (not notarized) 1.28.0 candidate from
  `0528f1b3`: the staged update from the installed public v1.27.0 app passed
  (`packaged-update-staging-smoke OK: 1.27.0 -> 1.28.0`), and installed uBO
  acceptance passed all ten checks, including provider restarts, persistence,
  close/LaunchServices reopen and native quit. The quit was a native
  `NSRunningApplication terminate` sent to the test process, not a keyboard
  Cmd-Q. One concurrent rerun failed mid-restart because two acceptance runs
  overlapped; the isolated rerun passed.
