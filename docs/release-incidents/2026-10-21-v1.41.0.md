# Blanc v1.41.0 release — October 21, 2026

Status: published and independently verified; public v1.41.0 is the baseline.
It published on the first attempt. The What's New page was live before the
release started, as the gate requires. The macOS and Windows updater
handoffs, and the packaged and Windows/Linux hand checks of the new features,
are pending.

## Scope

A minor release with these app changes merged since v1.40.0.

- **Clock Font & color (F54, #1026).** The Billboard Start Page's clock gets
  the iOS Lock Screen's Font & Color choices, from a **Clock** section in
  Customize or by right-clicking the clock: four OFL faces (Instrument Sans,
  Instrument Sans Condensed, Inter, and a clock-only Roboto Flex subset), a
  weight slider over each face's range, a Height done with the face's own
  width and weight axes (never a transform), **Automatic** or one of the
  eight Spaces presets with a Tone, and **Glass** or **Solid**. Every clock
  now has a shadow opposite its color. Six synced `newtabClock*` settings.
  Spec `docs/superpowers/specs/2026-10-21-billboard-clock-style-design.md`.
- **Start Page pins (#1029).** Up to eight pins per local profile
  (`start-page-pins.json`), drawn first on every layout, newest first. Pins
  come from a Billboard tile, a favorite on Ledger, Shelf or Tally, the
  Favorites page, or **Pin to Start Page** in the tab menu (web pages in
  non-private tabs). Profile Sync carries the Personal profile's list inside
  the encrypted settings payload as `startPagePins`; private Start Pages draw
  pins read-only. #1029 also made the Billboard tile's × visible in dark
  mode.
- **Fix:** the permission prompt hands the keyboard back to the page on
  screen, not a hidden tab that still reports focus (#1012).
- **Dependency:** `@ghostery/adblocker-electron` 2.18.2 → 2.20.1 (#799), with
  no user-facing change.

Release notes: [v1.41.0](../press/release-notes/v1.41.0.md) (prep #1031).
Stable mode, platforms `mac,windows,linux`, `BLANC_MAC_ARCHES=arm64,x64`, from
`9298b0916987ea9628bb2bee014717e85cd11628`. Electron stays 44.8.0 (Chromium
152.0.7977.167), so `src/main/ublock-platforms.json` is unchanged; 44.9.3 was
available but moving Chromium needs uBO's runtime review, which was not part
of this release. Between the prep merge and the release commit, only the
What's New page (#1032, website only) landed.

## The release run

One attempt, from `9298b091`. Every gate passed:

- **Press gate:** 4,204 unit tests, and 472 desktop scenarios with 3,154
  steps.
- **Builds:** the macOS identity and profile preflight, then both notarized
  builds.
- **Packaged checks:** fuses, byte-identical blocker payloads, compliance
  payloads, first run, release regressions, Workspace quit/restart, both live
  favicon matrices, and migration from public v1.40.0.
- **Native build:** the tag and draft were created, then native run
  `39691525432` (23:09–23:15 UTC) built and signed Windows and Linux.

The Sigstore loopback page in Safari timed out (`error getting code from
local server: timeout`), as in v1.17.2 and v1.32.0. Cosign fell back to
`Enter verification code:`; its out-of-band link was opened in Safari, the
owner signed in as `bnfy` and entered the code in Terminal, and the bundle
verified. The draft was published at 23:21:58 UTC on October 21, the
logged-out download smoke passed, `site/src/data/releases.json` was
refreshed, and the script exited 0.
