# Blanc v1.39.0 release — October 19, 2026

Status: published and independently verified; public v1.39.0 is the baseline.
It published on the third attempt. The first two stopped in the press gate,
before any tag or draft, on local focus failures in hover tests (below). The
adjacent v1.38.0 → v1.39.0 updater handoffs on macOS and Windows are
**pending**, as are the hand checks listed at the end.

## Scope

A minor release with these app changes merged since v1.38.0.

- **Auto-hide the Island (#964).** An opt-in, device-local setting
  (Settings → General, the View menu, ⌘⌥B / Ctrl+Alt+B). While the strip is
  hidden the active tab, Glance and the utility sheet fill the window. The
  strip comes back when the pointer is at or just above the top edge, after a
  300 ms rest within 40 px of the top, or from any Island surface such as ⌘L.
  It slides back over 200 ms, unless Reduce Motion is on. Turning it on keeps
  the strip shown for 5 s with a how-to tip. On macOS the traffic lights hide
  with the strip in the Island layout and now sit at Safari's and Finder's
  placement everywhere. A hover-opened panel closes once the pointer has been
  off its card for 200 ms unless it was used. Spec
  `docs/superpowers/specs/2026-10-19-auto-hide-island-design.md`, D29.
- **Tab Archive (F52, #977, #978).** Settings → General → Archive inactive
  tabs: Off (default), 12 hours, 1 day, 7 days or 30 days. It is
  device-local, and an update never turns it on. Only loose tabs are
  archived (not pinned, grouped or private), and never one that is active, in
  Glance, playing or capturing media, waiting on a permission prompt, or
  holding form input or a `beforeunload` handler. The per-profile
  `archive.json` keeps URL, title, icon, custom name, timestamps and Space
  name for 30 days, up to 500 entries. Restore from the ⌘L panel's Archived
  rows or History → Archived tabs (`/archive`). A fresh profile's onboarding
  offers it preset to 7 days (D5), and a one-time ⌘L notice follows the first
  archive (D6).
- **Sunrise Gold (#976).** A macOS-only Icon Composer app icon: a cream glass
  mark over gold, soft in Light and polished in Dark. In the Clear and Tinted
  icon styles the Dock shows the styled bundle icon. Windows was declined
  after the spike in #979, and Linux was dropped.
- **What's New tab (F51, #972).** After an update that changes
  `major.minor`, Blanc sends one cookie-less `HEAD` per launch, for up to
  seven days, to `blanc.day/whats-new/<major.minor>`. It opens the page once,
  as an ordinary tab, only after a 200. This is the first release that ships
  it.
- **Settings → General in cards (#975):** Island, Appearance, Start Page,
  Search, Browsing. The theme row is labeled Theme.

Release notes: [v1.39.0](../press/release-notes/v1.39.0.md) (prep #981).

## The release run

**Attempts 1 and 2 (no tag, no draft).** Both stopped in
`test:acceptance:desktop`, each on one auto-hide/hover scenario after its
retry: F1-26 ("Resting where the hidden address will appear…", strip never
revealed) and then F1-11 ("Hover-open works with vertical tabs", pointer
never reported inside). Diagnosis: the test window couldn't take focus.
`focusWindow` returned false, and macOS reported no frontmost process during
attempt 1 (screen locked). The auto-hide dwell sampler deliberately runs only
in a focused window (`src/main/main.js`), and `frontChromeWindow` swallows a
failed focus. Both scenarios passed 3 of 3 when run alone with the screen
unlocked, and in CI on macOS (both architectures), Windows and Linux. No code
changed between attempts.

**Attempt 3** ran with the Mac unlocked and left alone through the desktop
scenarios. Every gate passed:

- **Press gate:** 3,971 unit tests, and 423 desktop scenarios with 2,787
  steps.
- **Builds:** the macOS identity and profile preflight, then both notarized
  builds.
- **Packaged checks:** fuses, byte-identical blocker payloads, compliance
  payloads, first run, release regressions, Workspace quit/restart, both live
  favicon matrices, and migration from public v1.38.0.
- **Native build:** the tag and draft were created, then native run
  `39355024694` (01:43–01:49 UTC) built and signed Windows and Linux.

The Sigstore loopback page in Safari completed on the first try; the bundle
verified. The draft was published at 01:50:41 UTC on October 20 (21:50 EDT on the 19th), the logged-out download
smoke passed, and `site/src/data/releases.json` was refreshed.

## What's New tab did not open (owner report, October 19)

The owner's 1.39.0 didn't open the What's New page. Their profile shows the
first 1.39.0 launch at 01:51:46 UTC, one minute after publication and before
the page deployed, so that launch's check got no 200. The owner then opened
the Start Page pill, which still led to the changelog. That cleared
`whatsNewVersion`, and the check only ran while the pill was live, so the
owed tab was cancelled (`whatsNewTabRelease` is still empty). The owner then
decided the page must be live before a feature release publishes. #984 lets
the site build the next release's page ahead of it. #985 adds the
`release.sh` gate and stops a pill dismissal from cancelling an owed tab. The
updater handoff's What's New confirmation below therefore can't pass for
this release on the owner's Mac.
