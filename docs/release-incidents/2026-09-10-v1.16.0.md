# v1.16.0 screen sharing and tab handoff release — 2026-09-10

Status: published; authenticated public AppImage smoke passed. Adjacent
macOS and Windows updater handoffs are pending.

Blanc v1.16.0 was published from immutable source commit
`233c807cde4e27cb15813b3be146749e6e51725b` at `2026-09-10T19:34:24Z`:
<https://github.com/bnfy/blanc/releases/tag/v1.16.0>.

## Release contents

- Websites can request screen or window sharing through Blanc's trusted,
  centered confirmation. Computer audio is separately approved, each active
  share has an Island Stop control, and direct or legacy desktop-capture paths
  remain deny-closed. Linux continues into its system chooser.
- One-time tab handoffs now review and add bounded tab metadata in the current
  Blanc window.
- External links restore and foreground Blanc reliably. Mahjong Burst scores
  render thousands separators cleanly, and profile settings converge during
  sync.
- Electron 44.2.0 carries the Chromium fix for CVE-2026-85046. `js-yaml`
  4.3.2 fixes GHSA-2883-xcg3-v3hh.

## Screen-sharing disposition

- The release source pins separate capture runtimes by platform and verifies
  their bytes after packaging. macOS uses the accepted Playout capture trio;
  Windows and Linux use the accepted `c26127eb` trio, with Linux held in
  separate files so changes cannot drift into Windows.
- The owner accepted the private Mac conference result with moving video,
  clean system audio, background Stop, an independent second share, and
  microphone/camera continuity. Windows and Linux retain the owner-approved
  incomplete cells and waivers recorded in
  `docs/security-evidence/display-capture-broker-gate.md`; those cells are not
  relabeled as passes.
- The private conference packages used Electron 44.1.1. The owner authorized
  publication on the security-updated Electron 44.2.0 runtime without another
  conference campaign. No exact-public-package Meet rerun is claimed.
