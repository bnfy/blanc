# v1.17.0 workspace and desktop sign-in reliability release — 2026-09-13

Status: published at `2026-09-14T00:08:29Z` from immutable source
`c57eeb89f130a1f605cd465dcd2f8682a49acbc3`. Public artifact, exact-tag smoke,

Release: <https://github.com/bnfy/blanc/releases/tag/v1.17.0>.

## Scope

- Named Workspaces preserve live drafts, navigation history, and page state
  when switching, with reliable save, recovery, ordering, and deletion.
- Reviewed Claude and standard Microsoft and Google native OAuth callbacks ask
  before opening the installed application, preserve the exact callback across
  redirects and popup closure, and fail usefully when no handler is available.
- Blanc's built-in 1Password fill remains in the focused sign-in popup,
  including Google login windows. Unknown application schemes remain blocked,
  and callback secrets stay out of prompts and persistent browser data.
- Migration verification used the immediately preceding public v1.16.2 build.
