## Physical Windows and Linux check waiver

The owner did not install the private Windows installer or Linux AppImage on
affected machines. That leaves the updated UI's appearance and the
close-last-window, process-exit, and relaunch lifecycle unconfirmed on those
physical systems. CI packaging, signing, and smoke checks cannot fully catch
such defects. After this missing evidence and risk were stated, the owner
explicitly replied **“Waive Windows and Linux physical package checks for
v1.23.0”** on September 27, 2026. This waiver applies only to those physical
pre-release package checks. Automated candidate and public-release gates
remain required.

The owner also clarified **“we only test auto-update, not before it goes
live.”** Adjacent public macOS and Windows updater handoffs, including
**Restart Now**, remain post-publication checks and must be recorded as pending
until each is confirmed or separately waived. A direct installer launch is not
an updater handoff.
