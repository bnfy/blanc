# v1.22.0 mouse gestures and start-page polish release — 2026-09-23

Status: release preparation is underway. The public release, website deployment,
and adjacent updater handoffs are pending.

Release PR: pending.

## Scope

- Add device-local, customizable mouse gestures for navigation, tab actions,
  Reload, and opening the Island.
- Support Mac trackpads through Option plus a one-finger click-and-drag gesture,
  alongside right-button gestures for physical mice.
- Correct the onboarding dialog's opacity and corner geometry, and update its
  Island illustration to match the current resting Island.
- Improve Billboard clock spacing for narrow digits, meridiem labels, narrow
  windows, and 24-hour locales.
- Correct Mahjong hint, Undo, Rescue, and standalone documentation behavior.
- Advance the application version to 1.22.0 and the macOS bundle build number
  to 1220. Update the official Electron runtime from 44.4.3 to 44.4.5.

## Platform confirmation gate

Mouse gestures affect native pointer input across operating systems. Before
merging this release preparation, tagging, or running `npm run release`, the
owner must either confirm the private Windows and Linux candidates on affected
hardware or explicitly waive the remaining manual checks after their risk is
stated. Automated candidate signing, packaging, fuse, payload, and smoke gates
remain mandatory either way.
