# v1.22.0 mouse gestures and start-page polish release — 2026-09-23

Status: v1.22.0 is public and independently verified. The canonical website
deployment and adjacent macOS and Windows updater handoffs are pending.

Release PR: <https://github.com/bnfy/blanc/pull/426>.

## Scope

- Add device-local, customizable mouse gestures for navigation, tab actions,
  Reload, and opening the Island.
- Support trackpads through Alt/Option plus a one-finger click-and-drag gesture,
  alongside right-button gestures for physical mice.
- Correct the onboarding dialog's opacity and corner geometry, and update its
  Island illustration to match the current resting Island.
- Improve Billboard clock spacing for narrow digits, meridiem labels, narrow
  windows, and 24-hour locales.
- Correct Mahjong hint, Undo, Rescue, and standalone documentation behavior.
- Advance the application version to 1.22.0 and the macOS bundle build number
  to 1220. Update the official Electron runtime from 44.4.3 to 44.4.5.

## Platform confirmation gate

Mouse gestures affect native pointer input across operating systems. The owner
confirmed the trackpad gesture and close, process-exit, and relaunch lifecycle
on the corrected private Windows candidate. The Linux manual check was
explicitly waived below. Automated candidate signing, packaging, fuse, payload,
and smoke gates remained mandatory and passed on both platforms. The platform
confirmation gate is complete.

## Linux manual-check waiver

The missing Linux checks are physical-mouse gestures executing their assigned
actions without page-text selection or a stray context menu, plus closing the
last visible window, confirming the AppImage process exits, and relaunching it
successfully. Publishing without them risks Linux pointer handling or process
lifecycle differing from the automated packaged smoke. After that risk was
stated, the owner explicitly replied **“We will waive Linux”** on September 23,
2026. This waiver applies only to those manual Linux checks and does not waive
the successful automated validation run, public artifact verification, exact-
tag smoke, or updater handoff gates.
