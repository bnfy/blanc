## Scope

- The macOS bundle again declares both web schemes and the HTML document types
  needed for System Settings to classify Blanc as a browser. The macOS Finder
  document handoff admits only an existing, explicitly delivered HTML/XHTML file.
- The Windows installer registers Blanc as a browser candidate for HTTP and
  HTTPS and removes the registration on uninstall. Blanc opens Default apps for
  the user's choice and reads the actual UserChoice handlers before reporting
  that it is the default browser.
- The Linux desktop entry advertises Blanc as a WebBrowser for HTTP and HTTPS.
  It does not claim local HTML file handling.
- Electron advances to 44.4.3 with Chromium 152.0.7977.130. The macOS bundle
  build number advances to 1190. The JavaScript correctness lint gate also
  entered the release from `main`.
