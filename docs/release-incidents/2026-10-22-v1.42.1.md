# Blanc v1.42.1 release — October 22, 2026

Status: published and independently verified; public v1.42.1 is the baseline.
It published on the fourth attempt. None of the first three got as far as a
tag or draft. No What's New page: bug-fix releases skip that gate. The owner
confirmed the macOS and Windows updater handoffs from v1.42.0, the Windows
floating Island fix and the Glance card, and waived the Linux Glance check.

## Scope

A bug-fix release with these app changes merged since v1.42.0.

- **Fix: floating Island on Windows (#1052).** With Auto-hide set to Float,
  Chromium on Windows marked the covered strip document `hidden`, as on
  Linux, so the pill's size reports went stale. A pill that grew while
  covered (more tabs, a longer domain, a blocker count) was drawn wider than
  its float view and lost both rounded ends. The owner reported it on
  v1.42.0. In the Windows VM (200% scaling, a source build of main, no real
  input) the strip was `hidden`, and after four new tabs the reported pill
  was 463px wide against a real 481px. `coveredStripHeight` now leaves one
  strip row uncovered on Windows too, as #999 does on Linux. With the change
  the strip stayed `visible` and the reported width matched the pill at
  every step (408px, then 481px in a 523px view).
- **Changed: floating Glance card (#1050, owner-directed).** A deeper,
  mostly downward window shadow held in a ring 12px above, 20px at the sides
  and 28px below; 14px corners; the page inset 6px in the card's frame below
  the header with 8px corners, and no line under the header. #1050 recorded
  that its Windows and Linux VM checks were not done.

Release notes: [v1.42.1](../press/release-notes/v1.42.1.md) (prep #1053).
Stable mode, platforms `mac,windows,linux`, `BLANC_MAC_ARCHES=arm64,x64`, from
`b1ba294f7e28ee5e636734ce5d3abb2b68bcbf2c`. Electron stays 44.8.0 (Chromium
152.0.7977.167), so `src/main/ublock-platforms.json` is unchanged.

## The release runs

All four attempts ran from `b1ba294f`.

- **Attempt 1** stopped in the press gate's desktop acceptance run: 470 of
  472 scenarios passed. "The card stays put while a pushed Island slides in"
  (`glance.feature:538`) and "Closing under a resting pointer requires an
  exit before reopening" (`island-and-commands.feature:61`) each failed after
  two attempts on timing (the load average was about 5). Run alone, the
  1.42.1 commit passed 14 of 16 runs of the pair, failing only in the first
  three runs right after the gate, and then 10 of 10; v1.42.0 passed 16 of
  16 in alternating runs. The Glance scenario is the one #1050's own full run
  had failed once. Treated as load, and rerun.
- **Attempt 2** stopped at its first step: the 1Password authorization
  returned `promptError` (not approved).
- **Attempt 3** passed the whole press gate (4,215 unit tests, 472 of 472
  scenarios), then stopped at the start of the macOS build: the second
  1Password authorization, for the notarization credentials, timed out
  (`authorization timeout`). The build fails closed, so nothing was signed.
- **Attempt 4** passed every gate, with the owner approving both 1Password
  prompts:
  - **Press gate:** 4,215 unit tests, and 472 desktop scenarios with 3,154
    steps.
  - **Builds:** the macOS identity and profile preflight, then both
    notarized builds.
  - **Packaged checks:** fuses, byte-identical blocker payloads, compliance
    payloads, first run, release regressions, Workspace quit/restart, both
    live favicon matrices, and migration from public v1.42.0.
  - **Native build:** the tag and draft were created, then native run
    `39818577794` (16:58–17:06 UTC) built and signed Windows and Linux.

The Sigstore loopback page in Safari completed on the first try. The bundle
verified, the draft was published at 17:07:27 UTC on October 22, the
logged-out download smoke passed, `site/src/data/releases.json` was
refreshed, and the script exited 0.
