# Blanc v1.37.0 release — October 18, 2026

Status: published and independently verified; public v1.37.0 is the baseline.
It took three attempts. The first two stopped before the tag on checks that
hadn't caught up with merged behavior, so nothing from them was public. The
adjacent v1.36.0 → v1.37.0 updater handoffs on macOS and Windows, and the
Linux hand check of Move Group to New Window, are pending.

## Scope

A minor release with these app changes merged since v1.36.0.

- **Tab group colors and the group menu (#936).** A group can carry one of
  the eight Spaces preset colors, off by default: a tint on its block in the
  ⌘L panel and the side list, a dot before its name and colored Island dots.
  Right-clicking a group header, or its ⋮ button, opens one menu with the
  name, None plus the eight colors, New Tab in Group, Move Group to New
  Window, Ungroup and Close Group.
- **Ungrouped tab placement (#933).** `tabOrder` is the drawn order.
  Ungrouped tabs can sit above, between or below groups as runs; each run is
  its own section for the Island's dots, ⌥⌘↑/↓ and ⌘1–9; a new group appears
  where its tab was. Saved windows and spaces gain `sectionOrder`, and older
  entries open as v1.36.0 drew them.
- **Tab menu additions (#937).** New Tab Below; Close Tabs Above and Close
  Tabs Below as one Recently closed entry; Mute Site / Unmute Site for an
  exact host until quit, never saved or synced.
- **Pinned pages (F48; #927, renamed in #930).** A pinned tab records the
  page it was pinned on and returns there after a clean relaunch; crash
  recovery keeps the last page. Back to Pinned Page and Replace Pinned Page
  with Current are in the tab menu.
- **Island hover-open (#926, narrowed in #930).** Off by default, Settings →
  General. A 300 ms rest on the Island's address opens the panel.
- **Bang row icons (#922).** Bang rows show site icons from the profile, a
  device-level store (`bang-icons.json`, at most 300) or
  `blanc.day/bang-icons/<host>`; private tabs never ask.
- **Island tooltips and icons (#938).** The panel and the resting Island use
  Blanc's own tooltip (`data-tooltip`, and a new `blanc-chrome://tooltip/`
  view under the strip); a new Glance glyph; larger row icons.
- **Link children open ungrouped (#928)**, at the bottom like a plain new
  tab.
- **Private mode (#940).** No dashed outlines; a quiet "Private" label that
  shows its × on hover; the Island's top highlight toned down; the header on a
  private Start Page samples its wallpaper; the private Start Page shows the
  date.
- **Start Page footer (#939)** blends into each wallpaper with a per-phase
  scrim. **Island buttons (#941):** the pill's ✕ matches reload and favorite
  in size and hover, and disabled buttons stay visible.
- **Fixes:** the Linux Invite copy fallback (#903, found by the v1.36.0 hand
  checks), Island scroll bars no longer cover rows (#929), and dropping a tab
  at the empty pinned-section boundary (#904).

## Attempt 1: stopped in the press gate

Launched in Terminal.app from `a9cf3025` (#942). The unit tests passed, then
two desktop acceptance scenarios failed after their retries (388 of 390
passed):

- `ad-blocking.feature:47`: the pill shield's `title` was `''`, not "Blanc
  Blocker off for this site".
- `vertical-tabs.feature:21`: the Island footer's tab layout button's `title`
  was `''`, not "Turn vertical tabs on".

#938 had moved the Island's tooltips from `title` to `data-tooltip`, and its PR
notes that the desktop acceptance suite wasn't run. The UI was right; the test
hook's `pillShieldState` and `islandLayoutToggleState` still read `title`.
**#944** made them read `data-tooltip`. Both scenarios passed with it and
failed without it, and the full suite passed 390/390 locally.

## Attempt 2: stopped at the packaged Workspace check

Launched from `da922dcf` (#944 was the only new commit). The press gate (390
of 390 scenarios), both notarized builds, fuses, blocker and compliance
payloads, first run and release regressions passed. Then
`test:packaged:workspaces` failed:

```
actual:   [ordinary-two, ordinary-one]
expected: [ordinary-one, ordinary-two]
```

The smoke groups two tabs, pins the first, saves a space, then unpins the
first and pins the second. Since #933 the tab order is the drawn order and a
grouped pin leads its group, so the space saves and restores as [two, one]
with two pinned, which is what the Island draws. The smoke runs only inside
`release.sh`, so #933's CI never ran it (as with the stale migration smoke
behind #889 in v1.36.0). **#946** updated its expectations. Against attempt
2's signed arm64 build, the fixed smoke passed, and so did the checks after
it: migration from public v1.36.0 and both live-favicon matrices. A resume
wasn't possible because the build stamp names the source commit. No tag,
draft or release existed, so the version wasn't burned.

## Attempt 3: published

Launched from `70a4cc14` (#946 was the only new commit). Every gate passed
on the first try:

- **Press gate:** 3,794 unit tests, and 390 desktop scenarios with 2,558
  steps.
- **Builds:** the macOS identity and profile preflight, then both notarized
  builds.
- **Packaged checks:** fuses, byte-identical blocker payloads, compliance
  payloads, first run, release regressions, Workspace quit/restart, both live
  favicon matrices, and migration from public v1.36.0.
- **Native build:** the tag and draft were created, then native run
  `39109623658` (07:57–08:04 UTC) built and signed Windows and Linux.

The Sigstore loopback page completed in Safari without falling back to a
verification code. The draft was verified and published at 08:04:59 UTC, the
logged-out download smoke passed, and `site/src/data/releases.json` was
refreshed.
