# Android-only patches

Patches only the Android lane applies (`lanes/android.json`), against the files
pinned in `upstream-android/`. Shared patches in `patches/` apply to Android
only when the lane file lists them; a shared patch that needs different hunks
at Android's milestone gets `patches/variants/<version>/<same name>`, listed
in the lane file in its place. Numbering starts at 0101.

- `0101-android-identity.patch`: Blanc's launcher icon and app name, from
  `blanc/android/res/` (icons generated by `scripts/android-app-icons.js`).
