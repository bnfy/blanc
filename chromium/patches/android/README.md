# Android-only patches

Patches only the Android lane applies (`lanes/android.json`), against the files
pinned in `upstream-android/`. Shared patches in `patches/` apply to Android
only when the lane file lists them; a shared patch that needs different hunks
at Android's milestone gets `patches/variants/<version>/<same name>`, listed
in the lane file in its place. Numbering starts at 0101.

- `0101-android-identity.patch`: Blanc's launcher icon and app name, from
  `blanc/android/res/` (icons generated by `scripts/android-app-icons.js`).
- `0102-android-google-services-off.patch`: turns off the Google services
  Chromium runs by itself, in `SplitCompatApplication` right after the command
  line is read (native startup is too late on Android: the feature list is
  already set up): desktop's list (`blanc/common/background_services.h`:
  component updater, network time, autofill server) plus Android's (AI Mode's
  startup request, search prewarm and preconnects, DRM pre-provisioning at
  startup, the prediction-model download), and skips Chromium's first run
  (`disable-fre`: Google sign-in, Google's terms and the usage-reporting
  choice, which stays off by default). It also makes
  `GaiaCookieManagerService::TriggerListAccounts` a no-op on Android: with no
  Google sign-in, Blanc never lists the Google accounts in its cookie jar
  (sign-in metrics and Sync's session recorder called
  `accounts.google.com/ListAccounts` at every startup).
- `0103-android-blanc-java.patch`: puts Blanc's own Java test binary
  (`//blanc/android:blanc_android_junit_tests`) in the root build.
- `0104-android-island.patch`: hides Chrome's toolbar behind one HIDDEN
  browser-controls delegate and creates Blanc's Island
  (`//blanc/android:island_ui_java`) in `TabbedRootUiCoordinator`.
- `0112-android-top-color.patch`: colors the status bar with what's drawn at the
  page's top, as Safari does: `ChromeTabbedActivity.getBaseStatusBarColor` asks
  the Island's `TopColorSampler`, which reads the page's top row through
  `//blanc/android:top_color_bridge`, and falls back to Chrome's own color.
- `0113-android-start-page.patch`: registers the Start Page's profile
  preferences, `blanc.start.widgets` and `blanc.start.clock` (A5b), and the
  fork's pinned-shortcut list `blanc.prototype.start_page_pins`
  (`blanc/browser/ui/start_page_pins.inc`), which `blanc_pages_ui.cc` reads and
  writes for the fork's Start Page. None of them syncs.
- `0114-android-first-minute.patch`: starts the first-minute walkthrough
  (`org.chromium.blanc.firstrun.FirstMinute`) once the Island exists in
  `TabbedRootUiCoordinator`, and names Blanc's six interface languages
  (`blanc/android/island/res/xml/blanc_locales_config.xml`) as the app's
  `android:localeConfig`, so Android's App languages screen offers those six
  (A5c).
- `0115-android-launch-ping.patch`: links the launch ping's native sender
  (`//blanc/android:launch_ping_bridge`, `browser/launch_ping_bridge.cc`) into
  `//chrome/browser`, beside the other bridges, so the ping goes through
  Chromium's network stack and its NetLog.

A file dropped or moved in the lane keeps its applied edits in an existing checkout
(`apply.py` touches only the lane's files, and never deletes): restore a
Chromium file with `git checkout` there, and delete a moved Blanc file by hand.
