## Claim ledger

### Chrome

Claim: Chrome lets desktop users choose horizontal or vertical tabs, moving
the tab strip from the top of the window to the side.

Primary sources, accessed September 3, 2026:

- Google Chrome Blog, April 7, 2026:
  <https://blog.google/products-and-platforms/products/chrome/new-chrome-productivity-features/>
- Google Chrome Help:
  <https://support.google.com/chrome/answer/2391819?hl=en-GB>

### Blanc

Claim: Blanc replaces the traditional tab strip and toolbar with the Island;
tabs remain available when the user opens the Island, while the page remains
the visual center.

Release evidence:

- `v1.13.0:site/src/pages/features/island.astro`
- `v1.13.0:docs/marketing-claims.md`
- `v1.13.0:site/public/press/blanc-island-product-capture-v2.png`

The creative does not claim Blanc is objectively better, that every person
prefers this layout, or that Chrome lacks tab search or tab management.
