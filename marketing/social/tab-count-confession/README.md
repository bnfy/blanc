# Tab Count Confession

A fresh, participation-first social concept built from the August 28 conversion baseline. It asks for a reply before mentioning Blanc’s product, so the post can earn conversation rather than reading like another feature ad.

## Assets

- `tab-count-confession-feed-1080x1350.png` — X, Threads, Instagram feed, Facebook, and Substack.
- `tab-count-confession-vertical-1080x1920.png` — static full-screen source.
- `tab-count-confession-motion-1080x1920.mp4` — staged 8-second TikTok/Reel: hook → question → choices → reply prompt.
- `tab-count-confession-tiktok-1080x1920.mp4` — dedicated fast-cut TikTok execution: hook → escalating counts → poll choices → comment/follow CTA.
- `tab-count-confession-tiktok-cover-1080x1920.png` — dedicated TikTok profile-grid cover, with the question and choices centered inside the crop-safe area.
- Matching SVG source files are generated for both sizes.

The TikTok execution uses Blanc's monochrome paper/ink palette. The Blanc mark must appear only black on white or white on black—never on, inside, or visually backed by an accent color. Accent colors in the separate static campaign graphic do not change that logo rule.

Run `node marketing/social/tab-count-confession/render.js` from the repository root to regenerate the images. Then run `marketing/social/tab-count-confession/render-video.sh` to rebuild the MP4 from the four animation stages.

Run `marketing/social/tab-count-confession/render-tiktok-video.sh` for the dedicated TikTok cut. It intentionally uses hard cuts and rapid count escalation rather than repackaging the feed graphic as a slow slideshow.

> 0–10 / 11–30 / 31–100 / LOST COUNT

## Measurement

Capture at publication, 60–90 minutes, and 24 hours:

- follower/subscriber count;
- post reach or views;
- profile visits;
- replies/comments, reposts/shares, likes, and saves;
- link clicks and attributable downloads where available.

The conversion signal is follower/subscriber change, not raw views alone.
